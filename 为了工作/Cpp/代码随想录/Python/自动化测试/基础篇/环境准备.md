# 启动 mock 服务
先进到 mock_server 的目录，配置启动 mock_server ，这是模拟后端接口的服务。使用 uv run 直接运行

```bash
cd mock_server/api_server
```

```bash
uv run base/flask_service.py 
```



![1741326007563-e93ac032-7d58-4f7f-b9ef-65b125ba7b86.png](https://cdn.davidingplus.cn/images/2026/09/11/1741326007563-e93ac032-7d58-4f7f-b9ef-65b125ba7b86-742695.png)

uv 会自动安装编译依赖，并自动创建虚拟环境，使用虚拟环境运行。此时这个假的后端服务就起来了。

# 运行测试
我们在右上角新开一个终端窗口，运行自动化测试。进到项目根目录，执行 uv sync，手动安装一下自动化测试这个项目的依依

```bash
uv sync
```

```bash
source .venv/bin/activate
```

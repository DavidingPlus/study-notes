# 6. Redis工具类封装 - 从单节点到集群环境的实现

## 引言
在接口测试和实际项目开发中，我们经常需要从 Redis 中获取验证码等数据作为测试参数。为了提高代码复用性和可维护性，本文将介绍如何封装 Redis 工具类，实现对单节点及集群环境的数据操作。

## 环境准备
首先需要安装 Redis 相关依赖：

```bash
pip install redis
pip install redis-cluster  # 集群环境需要
```

## 1. 配置文件设计
采用 INI 格式的配置文件统一管理 Redis 连接信息：

```properties
[redis]
# 单节点配置
host = xxx.xxx.xxx.xxx
port = 6379
username = 
password = xxx
db = 0

# 集群节点配置 
nodes = host1:6379,host2:6379
```

## 2. Redis工具类实现
### 2.1 基础架构
```python
import redis
from redis.cluster import RedisCluster

class RedisClient:
    def __init__(self):
        self.config = {}
        self._init_config()
        self.redis = self._connect()
```

### 2.2 配置读取与连接建立
```python
def _init_config(self):
    """初始化配置"""
    cf = ConfigParser()
    self.config = {
        'host': cf.get('redis', 'host'),
        'port': cf.get('redis', 'port'),
        'username': cf.get('redis', 'username'),
        'password': cf.get('redis', 'password'),
        'db': cf.get('redis', 'db'),
        'nodes': cf.get('redis', 'nodes', fallback='')
    }

def _connect(self):
    """建立Redis连接"""
    try:
        if self.config['nodes']:
            # 集群模式
            nodes = self._parse_cluster_nodes()
            return RedisCluster(startup_nodes=nodes)
        else:
            # 单节点模式
            pool = redis.ConnectionPool(
                host=self.config['host'],
                port=int(self.config['port']),
                username=self.config['username'],
                password=self.config['password'],
                db=int(self.config['db'])
            )
            return redis.Redis(connection_pool=pool)
    except Exception as e:
        print(f"Redis连接失败: {e}")
        raise e
```

### 2.3 数据操作方法
```python
def get(self, key):
    """获取数据"""
    try:
        value = self.redis.get(key)
        if isinstance(value, bytes):
            value = value.decode('utf-8')
        return value
    except Exception as e:
        self._handle_error(e)
        return None

def set(self, key, value, expire=None):
    """设置数据"""
    try:
        return self.redis.set(key, value, ex=expire)
    except Exception as e:
        self._handle_error(e)
```

### 2.4 异常处理
```python
@classmethod
def _handle_error(cls, e):
    """统一异常处理"""
    if "MOVED" in str(e):
        print("请检查Redis是否使用了集群模式或主从复制")
        print("数据被迁移到了另外一个Redis实例")
    print(f"Redis操作错误: {e}")
    raise e
```

## 3. 使用示例
```python
# 初始化Redis客户端
redis_client = RedisClient()

# 获取数据
value = redis_client.get("test_key")
print(f"获取的值: {value}")

# 设置数据
redis_client.set("test_key", "test_value", expire=300)  # 5分钟过期
```

## 4. 核心特性
1. 支持单节点和集群两种模式
2. 配置与代码分离，通过配置文件统一管理
3. 自动识别环境并选择对应的连接方式
4. 统一的API接口，对上层应用透明
5. 异常统一处理
6. 数据类型自动转换

## 5. 注意事项
1. 根据实际环境选择合适的部署模式
2. 建议添加连接池管理和连接释放机制
3. 可以根据需要扩展更多Redis操作方法
4. 生产环境中需要考虑连接重试、超时等机制



通过这样的封装，我们实现了一个既支持单节点又支持集群环境的Redis工具类，具有以下优势：

+ 统一的配置管理
+ 简单的数据操作接口
+ 完善的异常处理机制
+ 数据类型自动转换
+ 良好的可扩展性

# 7. 高性能 Python 项目管理神器

## UV 简介
UV 是由 Astral 公司（同时也是代码格式化工具 ruff 的开发商）开发的 Python 项目管理工具。它使用 Rust 语言编写，具有以下特点：

+ **高性能**：相比传统工具性能提升显著
+ **功能集成**：整合了多个工具的功能
+ **标准化**：采用标准的 pyproject.toml 配置
+ **现代化**：支持最新的 Python 生态特性

## 安装
```plain
# MacOS (推荐)
brew install uv

# pip 安装
pip install uv

# 直接下载安装
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## 详细功能解析
### 1. 项目初始化与管理
UV 提供了两种项目初始化模式：

```bash
# 创建应用项目（默认模式）
uv init my_project

# 创建库项目
uv init --lib my_library
```

初始化后会生成如下项目结构：

```plain
my_project/
├── .git/
├── .gitignore
├── .python-version    # Python 版本配置
├── pyproject.toml     # 项目配置文件
├── README.md
└── src/              # 源代码目录
    └── my_project/
        └── __init__.py
```

### 2. 依赖管理系统
UV 的依赖管理系统设计得非常直观：

```bash
# 添加单个依赖
uv add pandas

# 添加多个依赖
uv add fastapi sqlalchemy

# 添加开发依赖
uv add --dev pytest black

# 移除依赖
uv remove sqlalchemy

# 同步虚拟环境
uv sync

# 更新特定包到最新版本
uv lock --upgrade pandas
```

依赖关系查看：

```bash
# 查看依赖树
uv tree

# 示例输出：
fastapi v0.100.0
├── pydantic v2.1.1
│   └── pydantic-core v2.4.0
└── starlette v0.27.0
```

### 3. Python 版本管理
UV 采用智能的 Python 版本检测和管理机制：

```bash
# 查看系统中可用的 Python 版本
uv python list

# 安装特定 Python 版本
uv python install 3.12.0

# 安装最新的兼容版本
uv python install ">=3.10,<3.11"

# 为项目设置 Python 版本
uv venv use 3.13.0
```

版本检测优先级：

1. UV 管理的 Python 安装
2. 系统 PATH 中的 Python
3. 需要时自动下载安装

### 4. 工作区（Workspace）功能
UV 支持 monorepo 风格的工作区管理，适用于管理多个相关项目：

```bash
# 创建工作区项目
uv init --workspace project_a

# 在工作区中创建另一个项目
cd project_a
uv init project_b
```

工作区特性：

+ 共享虚拟环境
+ 统一的依赖管理
+ 集中的 lock 文件
+ 独立的项目配置

### 5. 工具链集成
UV 提供了便捷的工具运行机制：

```bash
# 完整命令
uv tool ruff check .

# 简写形式
uvx ruff check .

# 安装工具
uv tool install ruff

# 更新工具
uv tool upgrade ruff

# 查看工具安装位置
uv tool where
```

### 6. 发布管理
UV 支持 Python 包的构建和发布：

```bash
# 构建包
uv build

# 发布到 PyPI
uv publish
```

pyproject.toml 构建配置示例：

```toml
[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"

[project]
name = "my-package"
version = "0.1.0"
```

## 最佳实践
1. **虚拟环境管理**

```bash
# 创建并激活虚拟环境
uv venv
source .venv/bin/activate
```

2. **依赖锁定**

```bash
# 生成锁文件
uv lock

# 基于锁文件安装依赖
uv sync
```

3. **CI/CD 集成**

```yaml
# GitHub Actions 示例
steps:
  - uses: actions/checkout@v3
  - name: Install UV
    run: curl -LsSf https://astral.sh/uv/install.sh | sh
  - name: Install dependencies
    run: uv sync
  - name: Run tests
    run: uvx pytest
```

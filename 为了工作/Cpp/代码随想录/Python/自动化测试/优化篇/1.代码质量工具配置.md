# 1. 代码质量工具配置

commit: 3f9b45dbb38e79a04e6ce127b654ce8c55d2ead0

## 开发依赖管理优化
+ 在 pyproject.toml 中新增 [project.optional-dependencies] 段
+ 添加 ruff>=0.1.0 作为开发依赖
+ 采用可选依赖模式，避免生产环境安装开发工具

## 代码检查规则配置
  配置了7类核心检查规则：

+ E: pycodestyle错误检查
+ W: pycodestyle警告检查
+ F: pyflakes静态分析
+ I: isort导入排序
+ B: flake8-bugbear潜在bug检查
+ C4: flake8-comprehensions列表推导式优化
+ UP: pyupgrade语法现代化

## 代码格式化标准
+ 行长度: 88字符（Black标准）
+ 目标版本: Python 3.12
+ 引号风格: 双引号统一
+ 缩进: 空格缩进
+ 逗号处理: 保留魔术逗号，提升git diff可读性

## 排除了不需要检查的目录
+ 版本控制目录 (.git, .svn)
+ 虚拟环境 (.venv, venv)
+ 缓存目录 (.ruff_cache, **pycache**)
+ 构建产物 (build, dist)
+ 项目特定: report 目录（测试报告）

##   使用方法
1. 安装开发依赖

  uv sync --extra dev

2. 检查代码质量

  ruff check .

3. 自动格式化

  ruff format .

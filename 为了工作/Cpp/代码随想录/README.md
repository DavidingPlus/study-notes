# 项目学习建议

## 时间充足

### 1. 先跑通项目

不要一开始死磕理论，优先搭环境，把代码跑起来。

### 2. 理解整体架构

搞清楚项目由哪些模块组成。

### 3. 阅读代码结构

了解：

- 每个文件负责什么
- 每个模块负责什么
- 有哪些核心函数和接口

此阶段可以暂时忽略实现细节。

### 4. 深入实现

理解：

- 核心逻辑
- 关键算法
- 重要设计思想

### 5. 重构与优化

尝试：

- 自己重写部分模块
- 增加功能
- 优化性能

---

## 时间紧张

### 1. 不必强求跑项目

直接阅读项目文档。

### 2. 理解架构

重点掌握：

- 模块划分
- 技术选型
- 项目流程

### 3. 看面试题

重点：

- 背项目面试题
- 整理项目亮点
- 查漏补缺

### 4. 直接写简历

参考项目提供的简历写法，尽快进入面试阶段。

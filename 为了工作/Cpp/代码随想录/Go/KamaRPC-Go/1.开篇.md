# 1. 开篇

# 项目目标
本项目旨在帮助 Go 语言开发者从底层原理出发，系统构建一个具备通信能力、并发模型与完整服务治理体系的高性能 RPC 框架。不同于只学习现成框架的使用方式，本项目通过“从零实现”的方式，打通网络协议、请求调度、服务发现、负载均衡与稳定性治理等关键链路，使开发者真正理解现代分布式系统的核心机制，并具备独立设计基础设施组件的能力。



**项目名称：kamaRPC-Go**  
**项目地址：**[**https://github.com/youngyangyang04/KamaRPC-Go**](https://github.com/youngyangyang04/KamaRPC-Go)

****

## 一、构建完整 RPC 通信与调用体系
项目基于 TCP 长连接实现高性能网络通信，设计自定义二进制协议（magic  | headerLen | bodyLen | requestId 等字段）. 通过长度字段分帧机制解决粘包与拆包问题，实现安全可靠的消息传输模型。开发者将深入理解半包处理、buffer 管理与循环读写机制，而非停留在简单 socket 使用层面。

在编解码层面，框架支持 JSON 与 Protobuf，并抽象出可插拔 codec 接口，实现编码方式解耦与扩展能力。同时支持 gzip 压缩策略，体现网络传输优化与工程实践能力。

在调用模型方面，客户端支持同步与异步调用机制，采用 Future 模型管理请求结果，并通过 requestId 实现多路复用能力，使单连接可承载高并发请求。服务端支持服务注册与反射调用（后续可扩展为代码生成 stub），实现“本地方法远程化”的完整调用链路

项目客户端实现连接复用与请求并发控制，使系统在高并发场景下保持稳定。

## 二、服务注册与发现体系
项目集成 etcd 作为注册中心，实现服务注册、租约续约（lease + keepalive）以及客户端 watch 服务变更机制。客户端维护本地缓存并动态更新可用节点列表，保证服务实例变更时的实时感知能力。

## 三、负载均衡与流量调度
框架内置多种负载均衡策略，包括：

+ Round Robin
+ Random
+ Weighted Round Robin

通过策略抽象接口，实现负载均衡算法可插拔设计，使流量调度具备扩展性与场景适配能力。

## 四、稳定性治理能力（生产级特性）
为增强系统在复杂环境下的抗波动能力，项目实现完整的治理能力体系：

**1. 熔断机制**  
基于滑动窗口统计错误率，当错误率超过阈值时自动进入熔断状态，并支持半开探测机制恢复服务调用。

**2. 限流机制**  
实现令牌桶算法，支持客户端与服务端双端限流，防止流量洪峰冲击系统。

## 项目目标与最终成果
通过 kamaRPC-Go 项目,将：

+ 深入掌握 RPC 框架核心实现原理
+ 理解 TCP 长连接、多路复用与并发调度机制
+ 掌握分布式系统中的注册发现与一致性基础
+ 理解负载均衡与流量调度的设计思想
+ 构建具备熔断、限流的稳定系统
+ 具备设计生产级网络框架与微服务基础设施的能力

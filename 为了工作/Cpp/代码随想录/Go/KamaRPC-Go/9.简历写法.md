# **一般简历写法**
**<font style="color:rgb(38, 38, 38);">KamaRPC-Go</font>** - 基于 Go 的高性能自研 RPC 框架

**项目描述：**  
基于 Go 从零实现高性能 RPC 框架，支持 TCP 长连接、自定义二进制协议、多路复用、服务注册发现、负载均衡、熔断与限流等能力，具备完整的服务治理体系。

**主要工作**

+ 基于 TCP 长连接设计通信模型，自定义二进制协议（magic、headerLen、bodyLen、requestId 等字段），通过长度字段与缓冲区管理机制解决粘包拆包与半包问题。
+ 实现可插拔 Codec 架构，支持 JSON 与 Protobuf 编解码，并引入 gzip 压缩优化网络传输效率。
+ 设计基于 requestId 的多路复用机制，实现单连接内并发请求与响应映射，并通过 Future 模型支持同步与异步调用。
+ 在服务端实现基于反射的服务注册与方法调用机制，支持动态服务加载与调用分发。
+ 构建连接池与连接复用机制，控制最大活跃连接数，并实现异常连接检测与回收。
+ 基于 etcd 实现服务注册、Lease 续租与 Watch 监听机制，客户端维护本地服务列表缓存实现动态服务发现。
+ 实现Weighted RoundRobin等多种负载均衡算法，提高多实例场景下的请求分发均衡性。
+ 实现熔断器（Closed/Open/HalfOpen 状态机）与令牌桶限流机制，提升系统在高并发及异常场景下的稳定性。
+ 基于 context 实现请求级超时控制与取消信号传播，避免超时请求导致资源泄漏。

**个人收获**

+ 深入理解 RPC 框架核心原理（协议设计、多路复用、服务治理）。
+ 强化 Go 并发编程能力，熟练掌握 goroutine、channel 与同步控制。
+ 掌握高并发场景下的连接管理与异常恢复设计。
+ 提升分布式系统基础能力（服务发现、负载均衡、熔断限流）。

# 进阶简历写法
**工作描述**：参与设计与实现基于 Go 语言的高性能分布式 RPC 框架，构建自定义二进制通信协议，支持多路复用、连接池、服务注册与发现、负载均衡、熔断与限流等核心能力，形成完整的服务治理体系，满足高并发低延迟场景需求。

**主要工作**：

+ **通信协议设计**：基于 TCP 长连接设计自定义二进制协议（magic、headerLen、bodyLen、requestId 等字段），通过长度字段与缓冲区管理机制解决粘包拆包与半包问题，实现稳定高效的数据传输。
+ **编解码与压缩机制**：实现可插拔 Codec 架构，支持 JSON 与 Protobuf 编解码，并集成 gzip 压缩机制，提升网络传输效率与框架扩展性。
+ **调用模型实现**：设计基于 requestId 的请求响应映射机制，实现单连接多路复用，并基于 Future 模型支持同步与异步 RPC 调用。
+ **服务注册与反射调用**：在服务端实现基于反射的服务注册与方法调用机制，通过本地服务映射表完成动态方法分发。
+ **连接池与资源管理**：实现客户端连接池与连接复用机制，控制最大活跃连接数，并设计异常连接检测与回收策略。
+ **服务发现机制**：基于 etcd 实现服务注册、Lease 续租与 Watch 监听机制，客户端维护本地缓存服务列表，实现动态服务发现。
+ **负载均衡算法**：实现Weighted RoundRobin等多种负载均衡策略，提高多实例部署场景下的请求分发效率。
+ **熔断与限流机制**：实现基于错误率统计的熔断器（Closed/Open/HalfOpen 状态机）以及令牌桶限流算法，提高系统在异常与高并发场景下的稳定性。
+ **超时与取消控制**：基于 context 实现请求级超时控制与取消信号传播，避免超时请求导致 goroutine 泄漏与资源占用。
+ **模块化架构设计**：对框架进行分层设计（transport、protocol、codec、registry、loadbalance、breaker），提升系统可扩展性与可维护性。

**项目难点**：

+ **TCP 粘包与半包处理**：通过自定义协议长度字段与读写循环机制解决流式传输中的数据边界问题，确保高并发场景下的数据完整性。
+ **多路复用与响应乱序问题**：基于 requestId 构建 Future 映射表，解决并发请求响应乱序匹配问题。
+ **连接异常与重连问题**：设计连接状态检测与失效连接清理机制，避免服务端重启后客户端复用旧连接导致异常。
+ **熔断状态机设计**：实现 Closed/Open/HalfOpen 状态切换逻辑，并设计半开探测机制避免误熔断与频繁震荡。
+ **超时与资源释放问题**：通过 context 取消信号向服务端传播，实现超时任务及时终止与资源回收。
+ **服务列表动态更新**：利用 etcd Watch 机制实时感知服务实例变化，并保证本地缓存一致性。

**个人收获**：

+ **分布式通信原理**：深入理解 RPC 框架核心原理，包括通信协议设计、序列化机制与远程调用模型。
+ **Go 并发编程能力**：在项目中大量使用 goroutine、channel 与同步机制，强化高并发编程能力。
+ **高并发系统设计**：理解连接池、多路复用、限流与熔断在高并发系统中的实际作用与实现方式。
+ **服务治理体系认知**：掌握服务注册发现、负载均衡与故障隔离等分布式系统核心能力。
+ **架构分层思维**：通过模块化拆分与接口抽象设计，提升系统可维护性与扩展性。
+ **工程问题定位能力**：通过调试连接失效、超时传播与并发异常问题，增强复杂系统问题分析与解决能力。

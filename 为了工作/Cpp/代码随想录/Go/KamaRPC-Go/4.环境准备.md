# 从零开始配置环境:
由于是轮子项目, 外部中间件只有利用到etcd,固然本项目不使用docker来部署项目

## 拉取项目
[https://github.com/youngyangyang04/KamaRPC-Go](https://github.com/youngyangyang04/KamaRPC-Go)

进入项目地址,拉下来项目

对应命令如下:

```go
git clone https://github.com/youngyangyang04/KamaRPC-Go.git
```

## 安装etcd
### windows:
windows安装etcd可以参考下面文章

[https://blog.csdn.net/skh2015java/article/details/80712214](https://blog.csdn.net/skh2015java/article/details/80712214)

### linux:
使用 apt 安装

```powershell
sudo apt update
sudo apt install etcd
```

启动etcd:

```powershell
sudo systemctl enable etcd
sudo systemctl start etcd
```

### mac
使用Homebrew 安装

```powershell
brew install etcd
```

安装完毕后进行验证

```powershell
etcd --version
```

安装成功后,若需要启动项目,每次可以输入etcd+回车进行临时启动

```powershell
etcd
```



## 启动项目客户端服务端demo
在项目主目录下, 开启3个终端,分别执行以下命令(需要先执行服务端再执行客户端)

```powershell
#第一个终端
cd cmd/server1
go build 
./server1
#第二个终端
cd cmd/server2
go build 
./server2
#第三个终端
cd cmd/client
go build 
./client
```



如果客户端输出如下,那么说明启动成功(如果没有启动成功,可能是etcd没有开启,检查一下)

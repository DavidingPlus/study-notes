# 熔断器
## 什么是熔断?
举个生活的例子: 一个电路设备过载或者电流过大的时候,熔断器会跳闸,暂时停止供电

而RPC中也是一样的,服务连续失败的时候,熔断器就会打开,暂停请求一段时间,防止错误不断放大

举例: 服务 A 调用 服务 B, 但是B 已经挂了 ,而A 还在疯狂重试

这会导致线程堆积 、连接池耗尽、A 也被拖死. 

这叫做雪崩效应



## 熔断代码封装讲解:
### 熔断器的三种状态
熔断器有三种状态,具体作用看注释

```go
type State int

const (
	Closed State = iota //正常放行
	Open //熔断打开，拒绝请求
	HalfOpen //半开状态，允许试探
)
```

### 结构体定义
熔断器结构体包含如下数据:

其中failureCount 和successCount 用来计算错误率,当达到一定错误率的时候,熔断器会开启,拒绝请求

而windowSize表示至少统计多少次请求,才会开始计算错误率, 如果不设置这个,那么第一次就调用失败了,错误次数和调用次数都是1,那么错误率将会达到百分百,就直接开启熔断了,这不合理, 固然需要设置一个值,表示达到这个值了,才开始进行错误率判断.

而错误率,就是failureThreshold.例如0.6 ,表示当错误率达到60%的时候,熔断就会开启

```go
type CircuitBreaker struct {
	mu sync.Mutex

	state State

	// 统计数据
	failureCount int
	successCount int

	// 配置参数
	windowSize       int           // 统计窗口大小（次数）
	failureThreshold float64       // 失败率阈值
	openTimeout      time.Duration // 熔断持续时间

	// 状态控制
	lastStateChange time.Time
	halfOpenProbe   bool // 半开状态下是否已有探测请求
}
func NewCircuitBreaker(windowSize int, failureThreshold float64, openTimeout time.Duration) *CircuitBreaker {
	return &CircuitBreaker{
		state:            Closed,
		windowSize:       windowSize,
		failureThreshold: failureThreshold,
		openTimeout:      openTimeout,
		lastStateChange:  time.Now(),
	}
}
```

### Allow() 
表示是否允许请求通过

当closed时候,表示熔断器关闭,允许通过

open就相反了,表示熔断器开启了,不允许通过

而HalfOpen 状态,此时只会允许一个探测请求,如果这个探测请求成功,那么会将熔断器关闭.通过halfOpenProbe字段维护. 避免半开阶段被大量请求冲垮

```go
func (cb *CircuitBreaker) Allow() bool {
	cb.mu.Lock()
	defer cb.mu.Unlock()

	switch cb.state {

	case Closed:
		return true

	case Open:
		// 熔断时间到了，进入半开
		if time.Since(cb.lastStateChange) > cb.openTimeout {
			cb.state = HalfOpen
			cb.halfOpenProbe = false
			return true
		}
		return false

	case HalfOpen:
		// 只允许一个探测请求
		if cb.halfOpenProbe {
			return false
		}
		cb.halfOpenProbe = true
		return true
	}

	return true
}
```

### 熔断器的状态切换
```go
package breaker

import (
	"log"
	"sync"
	"time"
)


func (cb *CircuitBreaker) RecordSuccess() {
	cb.mu.Lock()
	defer cb.mu.Unlock()

	switch cb.state {

	case Closed:
		cb.successCount++

	case HalfOpen:
		// 探测成功 → 恢复
		cb.toClosed()

	case Open:
		//按道理是不会进入这块的
		log.Println("理论不发生触发")
	}
}
func (cb *CircuitBreaker) RecordFailure() {
	cb.mu.Lock()
	defer cb.mu.Unlock()

	switch cb.state {

	case Closed:
		cb.failureCount++

		total := cb.failureCount + cb.successCount
		if total < cb.windowSize {
			return
		}

		rate := float64(cb.failureCount) / float64(total)
		if rate >= cb.failureThreshold {
			cb.toOpen()
			return
		}

		cb.resetCounts()

	case HalfOpen:
		// 探测失败 → 重新熔断
		cb.toOpen()

	case Open:
		// 已经熔断，不处理
	}
}
func (cb *CircuitBreaker) toOpen() {
	cb.state = Open
	cb.lastStateChange = time.Now()
	cb.resetCounts()
	cb.halfOpenProbe = false
}

func (cb *CircuitBreaker) toClosed() {
	cb.state = Closed
	cb.lastStateChange = time.Now()
	cb.resetCounts()
	cb.halfOpenProbe = false
}
func (cb *CircuitBreaker) resetCounts() {
	cb.failureCount = 0
	cb.successCount = 0
}

func (cb *CircuitBreaker) State() State {
	cb.mu.Lock()
	defer cb.mu.Unlock()
	return cb.state
}

```

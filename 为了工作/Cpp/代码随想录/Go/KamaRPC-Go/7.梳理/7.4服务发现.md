# 服务发现
```go
addr, err := c.getAddr(service)
```

在代码中, 有getAddr这个函数调用

这一步是：去注册中心查服务地址(在项目中我们使用的是etcd作为本项目的注册中心)

## 注册中心的作用:
我们举个例子, 如果我们不使用注册中心,那么我们在客户端可能这么写代码

```go
conn, _ := net.Dial("tcp", "192.168.1.10:9091")
```

但是原先服务器部署在192.168.1.10这个ip上, 现在迁移到192.168.1.25这个ip上,此时客户端需要更改代码, 尽管我们不将ip地址写到代码层面上,写到配置文件上, 我们也需要手动更改配置文件. 这很麻烦. **这是强耦合**

注册中心, 可以理解为一个“服务地址通讯录”,如果我们没有这个通讯录, 那么我们需要自己记住我们朋友的手机号,而且当朋友换手机号了,我们也不会知道.

但是有了这个“通讯录”, 朋友更换号码,可以更新这个通讯录, 此时,我们只要找到这个朋友,就能找到朋友的电话号码,从而拨打电话

了解完注册中心作用后, 我们来讲解我们是如何封装这个注册中心代码的

## 注册中心(etcd)代码封装讲解
在本项目中,我们使用的是etcd当作注册中心, 我们在看代码前先来思考我们为什么选择etcd?

1. 强一致性: etcd 使用的是raft共识算法,它保证数据在多节点之间强一致、不会出现读到脏数据、不会出现脑裂(**如果地址数据不一致，会发生客户端调用不存在的节点,服务状态混乱**) 至于什么是raft算法,可以阅读下列文章:[Raft算法详解](https://zhuanlan.zhihu.com/p/32052223)
2. 原生支持 TTL（自动过期）: 如果服务崩溃：那么过期了,就可以自动删除服务端这边的key,这叫做**自动健康检查 ,etcd原生支持,非常优雅**
3. 支持 Watch 机制（实时通知）: etcd中的Watch机制,可以监听某个key前缀,当发生变化时,可以自动通知客户端. 像代码中/kamaRPC/services/Arith/ 新增或删除实例的时候,客户端就会收到通知,此时客户端就可以做一些特定的操作比如实时更新本地缓存

好了,了解完etcd的作用,我们就可以阅读封装etcd相关的代码了

### 结构体定义:
```go
type Registry struct {
	client *clientv3.Client
	prefix string

	mu       sync.RWMutex
	services map[string]map[string]Instance

	ctx    context.Context
	cancel context.CancelFunc
}

```

便于实现本地缓存 + 实时同步的服务发现系统, 本质上做了两件事:

服务注册（服务端使用）与 服务发现（客户端使用）

即服务端调用封装好的 Register, 客户端调用封装好的客户端调用 Discover

### NewRegistry
```go
func NewRegistry(endpoints []string) (*Registry, error) {
	//这里建立的是和etcd的连接
    cli, err := clientv3.New(clientv3.Config{
		Endpoints:   endpoints,
		DialTimeout: 5 * time.Second,
	})
	if err != nil {
		return nil, err
	}

	ctx, cancel := context.WithCancel(context.Background())
    //services指的是通过服务名与地址拿取到特定服务的实例信息
    //用于客户端本地缓存
	return &Registry{
		client:   cli,
		prefix:   "/kamaRPC/services/",
		services: make(map[string]map[string]Instance),
		ctx:      ctx,
		cancel:   cancel,
	}, nil
}
```

### Register
具体看注释,讲解的很详细了

```go
func (r *Registry) Register(service string, ins Instance, ttl int64) error {
	//向 etcd 申请一个“带过期时间的租约”,比如 ttl = 10 秒
    //表示如果 10 秒内不续租，这条记录会自动删除
    //解决的是服务端挂了怎么办?当然是要将它从注册中心去除
    leaseResp, err := r.client.Grant(r.ctx, ttl)
	if err != nil {
		return err
	}
    //写入 key,例如:/kamaRPC/services/Arith/localhost:9091
    //通过key可以知道服务名+实例地址
	key := fmt.Sprintf("%s%s/%s", r.prefix, service, ins.Addr)

	_, err = r.client.Put(r.ctx, key, ins.Addr, clientv3.WithLease(leaseResp.ID))
	if err != nil {
		return err
	}
    //持续向 etcd 发送心跳,只要服务还活着,那么租约就会被续期
    //保证etcd一直会拥有该服务的地址信息
	ch, err := r.client.KeepAlive(r.ctx, leaseResp.ID)
	if err != nil {
		return err
	}
    //通过消费返回的通道信息,维持租约
    //实现了自动健康检查
	go func() {
		for {
			_, ok := <-ch
			if !ok {
				return
			}
		}
	}()

	return nil
}
```

### Discover与其相关的函数
若非第一次查找当前service,客户端会从缓存的信息中拿取之前缓存过的服务地址

若时第一次查找当前service,客户端会调用initService从etcd中查找, 找到后缓存服务地址与监听该服务

这样做的好处是:

+ 不用每次都访问 etcd,减少了网络开销

watch:实时感知服务变化,当key发生变化的时候,可以自动通知客户端

方便对本地缓存进行加入和缓存删除的操作

若wathc断开了,也会进行time.Sleep(time.Second)操作,重新进行watch操作

```go
func (r *Registry) Discover(service string) ([]Instance, error) {
	r.mu.RLock()
	if _, ok := r.services[service]; ok {
		instances := r.copyInstances(service)
		r.mu.RUnlock()
		return instances, nil
	}
	r.mu.RUnlock()

	// 第一次发现，初始化
	if err := r.initService(service); err != nil {
		return nil, err
	}

	return r.copyInstances(service), nil
}

// 初始化服务缓存
func (r *Registry) initService(service string) error {
	r.mu.Lock()
	defer r.mu.Unlock()

	// 防止重复初始化
	if _, ok := r.services[service]; ok {
		return nil
	}

	key := fmt.Sprintf("%s%s/", r.prefix, service)

	// 先 Get 一次
    //从 etcd 拉取当前所有实例
	resp, err := r.client.Get(r.ctx, key, clientv3.WithPrefix())
	if err != nil {
		return err
	}

	r.services[service] = make(map[string]Instance)

	for _, kv := range resp.Kvs {
		addr := string(kv.Value)
        //写入本地缓存
		r.services[service][addr] = Instance{Addr: addr}
	}

	// 启动 watch
	go r.watch(service)

	return nil
}

func (r *Registry) copyInstances(service string) []Instance {
	r.mu.RLock()
	defer r.mu.RUnlock()

	var instances []Instance
	for _, ins := range r.services[service] {
		instances = append(instances, ins)
	}
	return instances
}

func (r *Registry) watch(service string) {
	key := fmt.Sprintf("%s%s/", r.prefix, service)

	for {
		watchChan := r.client.Watch(r.ctx, key, clientv3.WithPrefix())

		for watchResp := range watchChan {
			for _, event := range watchResp.Events {
				switch event.Type {

				case clientv3.EventTypePut:
					addr := string(event.Kv.Value)
					r.mu.Lock()
					r.services[service][addr] = Instance{Addr: addr}
					r.mu.Unlock()

				case clientv3.EventTypeDelete:
					deletedKey := string(event.Kv.Key)
					addr := strings.TrimPrefix(deletedKey, r.prefix+service+"/")
					r.mu.Lock()
					delete(r.services[service], addr)
					r.mu.Unlock()
				}
			}
		}

		// watch 断了，稍后重连
		time.Sleep(time.Second)
	}
}
```

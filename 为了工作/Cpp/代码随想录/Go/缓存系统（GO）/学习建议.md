# 学习建议

**完成项目指导时间：如果【基础要求】里的基础，每天6个小时，7天完成。**

**如果没有基础，边学边做，每天 6-8个小时，需要 15天左右。**

**代码量：2000 行左右（除去测试代码）**

### 基础要求：

* **Go 语言基础**<font style="color:rgb(13, 13, 13);">：包括goroutine、channel、接口等核心概念</font>
* **<font style="color:rgb(13, 13, 13);">缓存原理</font>**<font style="color:rgb(13, 13, 13);">：缓存淘汰策略（LRU、LFU等）</font>
* **网络编程**<font style="color:rgb(13, 13, 13);">：gRPC基础、HTTP协议、TCP/IP</font>

### <font style="color:rgb(13, 13, 13);">循序渐进的学习顺序</font>

1. **从单机缓存开始**<font style="color:rgb(13, 13, 13);">：</font>
   * <font style="color:rgb(13, 13, 13);">先理解 </font>`ByteView`<font style="color:rgb(13, 13, 13);">、</font>`lruCache`<font style="color:rgb(13, 13, 13);"> 等核心数据结构</font>
   * <font style="color:rgb(13, 13, 13);">熟悉 </font>`Cache`<font style="color:rgb(13, 13, 13);"> 和基本的缓存操作</font>
2. **理解分组缓存**<font style="color:rgb(13, 13, 13);">：</font>
   * <font style="color:rgb(13, 13, 13);">学习 </font>`Group`<font style="color:rgb(13, 13, 13);"> 结构及其工作原理</font>
   * <font style="color:rgb(13, 13, 13);">掌握缓存加载、过期策略等机制</font>
3. **研究分布式扩展**<font style="color:rgb(13, 13, 13);">：</font>
   * <font style="color:rgb(13, 13, 13);">一致性哈希算法实现</font>
   * <font style="color:rgb(13, 13, 13);">节点间通信协议</font>
   * <font style="color:rgb(13, 13, 13);">服务注册与发现</font>
4. **深入高级特性**<font style="color:rgb(13, 13, 13);">：</font>
   * <font style="color:rgb(13, 13, 13);">缓存击穿防护</font>
   * <font style="color:rgb(13, 13, 13);">分段锁与高并发优化</font>
   * <font style="color:rgb(13, 13, 13);">优雅关闭与资源管理</font>

### <font style="color:rgb(13, 13, 13);">代码阅读方式</font>

1. **绘制组件关系图**<font style="color:rgb(13, 13, 13);">：</font>
   * <font style="color:rgb(13, 13, 13);">梳理核心接口和实现类</font>
   * <font style="color:rgb(13, 13, 13);">理清组件间的调用关系</font>
2. **断点调试关键流程**<font style="color:rgb(13, 13, 13);">：</font>
   * <font style="color:rgb(13, 13, 13);">Set/Get操作的完整链路</font>
   * <font style="color:rgb(13, 13, 13);">分布式场景下的数据同步</font>
3. **编写单元测试**<font style="color:rgb(13, 13, 13);">：</font>
   * <font style="color:rgb(13, 13, 13);">为关键组件编写测试用例</font>
   * <font style="color:rgb(13, 13, 13);">使用基准测试验证性能优化</font>
4. **模拟故障场景**<font style="color:rgb(13, 13, 13);">：</font>
   * <font style="color:rgb(13, 13, 13);">节点宕机时的系统行为</font>
   * <font style="color:rgb(13, 13, 13);">网络分区下的一致性保证</font>

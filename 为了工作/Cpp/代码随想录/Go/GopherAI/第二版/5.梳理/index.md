# 5. 梳理





第二版增加了4个部分：



+ 文件上传: 由于项目中引入了 RAG，因此需要用户上传相关文件以作为检索和生成的知识来源，文件服务正是为此而设计。
+ RAG: 是 GopherAI 第二版中的核心功能组件，专注于提供高效、准确的知识检索和问答服务支持获取用户所有会话列表和特定会话的历史记录。AI模型类型可配置（如GPT等），使用上下文管理器管理不同用户的AI助手实例。
+ MCP:  是 GopherAI 第二版中用于 **外部工具调用和多渠道能力扩展** 的核心组件。它与 RAG 模块类似，都是为了增强 LLM 的功能，但 MCP 更偏向 **对接外部服务和插件工具**，实现动态信息获取和功能调用。
+ TTS:   在 GopherAI 第二版中提供了将文本转换为语音的能力，是模型生成语音输出的核心组件。它的设计目标是将用户输入的文本，通过标准化的 API 调用生成高质量的音频

# 技术架构图

![1766595242170-40888112-3476-4a5f-87f5-aa1449929b83.png](./img/WlMH_DOj0M5i3ol3/1766595242170-40888112-3476-4a5f-87f5-aa1449929b83-572123.png)

这张架构图展示了 GopherAI 整个系统的核心组成部分，包括：\
**业务服务、AI 推理、第三方平台、基础设施、消息队列、数据库，以及前后端交互流程。**

你可以把它理解为：\
**“用户从输入一个问题 → 后端处理 → AI 推理 → 数据落库 → 前端实时显示”** 的全链路流程图。

**从技术架构图上来看,其实和第一版的整个流程是差不多的.**(**详细介绍可以看第一版的项目介绍部分**)

但是其实在第二版中,增加了四部分:

* 文件上传服务
* RAG服务
* MCP服务
* 语音服务

相应的介绍在第五点梳理中

## 业务服务所使用的基础工具与关键组件

这一部分,也是和第一版类似的,但依旧会有些不同

原先我们是用 **go-redis / redis/v8版本,现在改成了go-redis / redis/v9版本**

因为v9提供向量化一系列的操作,这是我们更改版本的原因

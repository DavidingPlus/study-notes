# 2.本项目学习过程

## 不同基础录友的时间参考
每天大概4-5个小时。

| 录友背景 | 预计时间 | 建议 |
| --- | --- | --- |
| 有go成熟开发经验 | **7天左右** | 可完整吃透二代所有模块 |
| 刚学习go开发 | **10～14 天** | 重在理解 RAG / MCP 思路 |
| 完全没做过一版 | ❌ 不建议直接上第二版 | 建议先完成第一版 |


### **阶段一：环境准备 & 架构理解**
适合所有人，不能跳过。

+ 理解第二版新增模块的整体架构：
    - RAG 服务
    - 文件上传服务
    - MCP 服务
    - TTS 服务
+ 熟悉：
    - 向量化流程
    - 用户级 RAG 隔离思路
    - MCP 的客户端 / 服务端模型

这一阶段的目标不是写代码，而是 **“想明白为什么要这么做”**。

---

### **阶段二：文件上传 + RAG 基础能力（3～5 天）**
这是第二版**最核心、最有价值**的一块。

+ 文件上传（用户级隔离）
+ 文档解析 & 切分
+ 向量化 & 存储
+ 基于用户维度的向量检索
+ RAG 问答串联进 AI Chat 流程

这一阶段会明显感觉到开发**能力在升级**。

---

### **阶段三：MCP 服务接入**
这部分代码量不大，但**思想很新**。

+ 理解 MCP 的设计初衷
+ 实现 MCP Server（天气服务）
+ 实现 MCP Client
+ 让 AI 通过 MCP 调用外部能力

这是一个**面试加分项模块**，不在于写多复杂，而在于你能不能讲清楚。

---

### **阶段四：语音识别 / TTS 接入**
偏工程整合，难度中等。

+ 接入 TTS 服务
+ 设计音频返回接口
+ 与现有会话系统融合
+ 处理同步 / 异步问题

这一步能让你的项目**从“AI 应用”升级为“多模态 AI 平台”**。

---

###  **阶段五：整体联调 & 架构回顾**


+ 多模块联调
+ 数据隔离验证
+ RAG 准确性测试
+ 回看架构设计是否合理
+ 梳理简历可写点 & 面试表达

**主要看能不能在面试中把项目讲漂亮**。

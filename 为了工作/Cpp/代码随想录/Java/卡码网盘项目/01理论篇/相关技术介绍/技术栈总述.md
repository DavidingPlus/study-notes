## 业务服务与模块落点

| 模块 | 角色 | 关键技术 |
| --- | --- | --- |
| `networkdisk-auth` | 认证服务，端口 `8090` | Spring Boot、Sa-Token、Redis、Dubbo、JWT |
| `networkdisk-gateway` | 网关服务，端口 `8081` | Spring Cloud Gateway、LoadBalancer、Sa-Token Reactor、Sentinel、Nacos |
| `networkdisk-files` | 文件服务，端口 `8082` | Spring MVC、MyBatis-Plus、Dubbo、Elasticsearch、RocketMQ、Canal、OSS、FastDFS |
| `networkdisk-recycle` | 回收站服务，端口 `8084` | Spring MVC、MyBatis-Plus、Dubbo、Elasticsearch |
| `networkdisk-share` | 分享服务，端口 `8085` | Spring MVC、MyBatis-Plus、Dubbo、XXL-Job、Delay Message |
| `networkdisk-user` | 用户服务，端口 `8086` | Spring MVC、MyBatis-Plus、Dubbo |
| `networkdisk-ai` | AI 文档分析服务，端口 `8087` | Spring MVC、RocketMQ、Apache Tika、PostgreSQL、pgvector、OpenAI-compatible Provider |
| `networkdisk-app` | 业务聚合应用 | 聚合 `networkdisk-share`、`networkdisk-files`、`networkdisk-user` |
| `networkdisk-notice` | 通知服务 | Datasource、Lock、Dubbo、XXL-Job |
| `networkdisk-engine` | 文件引擎能力模块 | FastDFS、Elasticsearch、MQ |

# 项目介绍

该项目是一个基于 `Spring Boot 3 + Dubbo 3 + Vue 3` 构建的前后端分离、多模块网盘系统，核心业务包括认证、文件管理、搜索、分享、回收站，以及新增的 AI 文档分析能力。**前端**采用 `Vue3 + Vite + Element Plus`实现，通过网关和业务接口完成交互。**后端**采用多模块 Maven 工程，主要模块包括 `auth`、`gateway`、`files`、`share`、`recycle`、`user`、`ai` 等。

### 技术选型与架构设计

* **前端技术**：Vue 3 + Vite + Element Plus
* **核心框架**：Spring Boot 3.2.2 + Spring MVC
* **网关与服务治理**：Spring Cloud Gateway + Nacos
* **服务通信**：Dubbo 3
* **数据库访问**：MySQL + MyBatis-Plus
* **缓存与分布式能力**：Redis + JetCache + Redisson
* **消息驱动**：Spring Cloud Stream + RocketMQ
* **搜索能力**：Elasticsearch + Canal
* **文件存储**：StorageEngine 抽象 + Local / OSS / FastDFS 多实现
* **AI 能力**：Apache Tika + OpenAI-compatible Provider（当前默认配置为 DashScope/Qwen 兼容接口）+ PostgreSQL + pgvector

### 核心功能

* **用户模块**
  * 注册：创建用户并初始化用户根目录。
  * 登录：服务端会调用 Sa-Token 登录，同时签发 JWT，并把 JWT 写入 Redis。
  * 鉴权：业务接口主要通过 AOP 统一校验 `Authorization` 中的 JWT，并比对 Redis 中的登录态；部分接口通过 `@LoginIgnore` 放行。
  * 退出：清理 Redis 登录信息，并注销登录态。
* **文件模块**
  * 文件列表、面包屑、目录树。
  * 新建文件夹、重命名、移动、复制、逻辑删除。
  * 单文件上传、秒传、分片上传、断点续传、分片合并。
  * 文件下载、在线预览。
* **搜索模块**
  * 支持关键字检索、拆词/子串模糊命中、高亮返回。
  * 优先 ES 查询，ES 未命中或不可用时回退 MySQL。
  * 支持 Canal 增量同步 `user_file -> user_file_index`。
* **分享模块**
  * 创建分享、取消分享、分享详情查询。
  * 匿名访问分享页（`@LoginIgnore`）。
  * 提取码校验、分享文件列表、分享文件下载。
  * 分享过期控制：访问时校验 + Redisson 延迟队列自动清理。
* **回收站模块**
  * 查看已删除文件。
  * 批量还原（恢复 `deleted=0`）。
  * 批量彻底删除。
  * 支持选中目录时递归处理子节点。
* **AI 模块**
  * 提供 AI 能力探测、文档建索引、生成摘要、生成标签、单文件问答接口。
  * 文件服务会在上传、秒传、分片合并成功后，对支持的文档类型异步发送“AI 预热”消息。
  * AI 服务消费消息后，执行“建索引 + 摘要 + 标签”预处理，减少用户首次打开文档时的等待时间。
  * 单文件问答会优先走 pgvector 检索相关片段，再把片段上下文交给大模型回答。

### 项目亮点

* **文件存储抽象**
  * 通过 `StorageEngine` 解耦业务与底层存储实现，业务层不直接依赖本地磁盘、OSS 或 FastDFS 的具体 SDK。
* **大文件传输能力**
  * 支持分片上传、断点续传、秒传、分片合并。
  * 下载和预览采用流式处理，降低大文件 IO 的内存压力。
* **搜索双通路设计**
  * 平时优先使用 Elasticsearch 提供更好的检索性能，同时通过 `Canal` 做 `user_file -> user_file_index` 的增量同步；
  * ES 不可用或未同步完成时，仍可回退到 MySQL，保证功能可用性。
* **统一鉴权与 ID 安全**
  * 登录态校验通过 JWT + Redis + AOP 组合完成。
  * 多数文件 ID 对外使用加密字符串，避免直接暴露数据库主键。
* **分享延迟清理**
  * 使用 Redisson 延迟队列调度过期分享的清理任务，避免依赖单机定时轮询。
* **AI 异步预热与检索增强问答**
  * 文件上传后不阻塞用户请求，而是异步完成索引、摘要、标签生成。
  * 单文件问答先做向量检索再提问，属于典型的轻量级 RAG 落地方案。

### 学习这个项目你可以收获

该项目适合作为后端学习与面试项目，原因是它不仅有 CRUD，还覆盖了真实业务中常见的多种基础设施协作方式。你将学到：

* **需求分析能力**：针对上传、搜索、分享、AI 等不同场景选择不同技术方案
* **系统设计能力**：把 Redis、ES、Dubbo、MQ、对象存储、pgvector 放到合理的业务位置
* **并发与异步思维**：在文件传输、延迟任务、AI 预热等场景中减少同步阻塞
* **数据一致性与同步机制**：理解 MySQL 与 Elasticsearch 的索引同步，以及业务表与 AI 结果表的关系
* **可扩展性设计**：通过模块拆分为后续权限体系、团队协作、多文档问答等能力预留空间

# 基础配置

## 数据源配置

sql的源文件在星球的帖子中获取，需要下载后再进行下一步

### 操作步骤

1. 创建名为`network_disk`的database
2. source /xxxx/xxx/xx/DDL\_network\_disk.sql 即可
3. 在数据源配置信息中，将账号密码改为自己的即可

# AI模块配置

启动AI模块时，需要确认已经部署好了RocketMQ、pgvector以及创建好表networkdisk\_ai

还需要配置好自己的api-key，项目中使用的是阿里百炼的免费模型，可以根据你喜欢的模型进行调用

复制下方API Key至networkdisk-business/networkdisk-ai/src/main/resources/application.yml中，实际生产中一定要配置为环境变量，不可泄漏

# 基础启动流程

## 前端

cd disk-by-cursor

下载依赖：npm install

启动项目：npm run dev

## 后端

运行项目实际业务模块，依次启动即可

* NetworkdiskFilesApplication
* NetworkdiskUserApplication
* NetworkdiskShareApplication
* NetworkdiskRecycleApplication
* NetworkdiskAuthApplication

> Auth在注册/登录时会Dubbo调user和files，在使用注册、登录链路时需要确认Nacos、user、files的情况

* NetworkdiskAiApplication

> 如果后端还没有准备好AI相关配置，可以先不启动

* NetworkdiskGatewayApplication

> 本地可以先不启动networkdisk-gateway

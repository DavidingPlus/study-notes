<font style="color:rgb(64, 64, 64);">——— 第三章 烹饪步骤（SQL核心实现）———</font>

<font style="color:rgb(64, 64, 64);">🔥</font><font style="color:rgb(64, 64, 64);"> 每日排行榜SQL详解：</font>

```sql
-- 今日学霸TOP10查询
SELECT 
  author_id,
  username,          -- 取用户信息就像准备配菜
  avatar_url,
  COUNT(note_id) AS count,  -- 主食材：笔记数量
  RANK() OVER (ORDER BY COUNT(note_id) DESC) AS rank -- 关键调料：排名
FROM note
JOIN user ON author_id = user_id
WHERE DATE(created_at) = CURDATE() -- 只要今天的数据
GROUP BY author_id                 -- 按用户分组统计
ORDER BY count DESC
LIMIT 10;                          -- 只要前十名
```

<font style="color:rgb(64, 64, 64);">❗</font><font style="color:rgb(64, 64, 64);"> 避坑指南：</font>

1. <font style="color:rgb(64, 64, 64);">一定要给created_at字段加索引 → 就像快火炒菜</font>
2. <font style="color:rgb(64, 64, 64);">使用DATE()函数 → 避免时间戳精度问题</font>
3. <font style="color:rgb(64, 64, 64);">预计算排名 → 减少服务端计算压力</font>

<font style="color:rgb(64, 64, 64);">🌋</font><font style="color:rgb(64, 64, 64);"> 热力图SQL进阶版：</font>

```sql
WITH 
DailyNoteCounts AS ( -- 第一步：准备基础食材
  SELECT 
    author_id,
    DATE(created_at) AS date,
    COUNT(*) AS count
  FROM note
  WHERE created_at >= NOW() - INTERVAL 95 DAY -- 最近95天
  GROUP BY author_id, date
),
RankedData AS ( -- 第二步：加入秘制酱料
  SELECT 
    *,
    RANK() OVER (PARTITION BY date ORDER BY count DESC) AS rank
  FROM DailyNoteCounts
)
-- 第三步：装盘上菜
SELECT * FROM RankedData 
WHERE author_id = #{userId}
ORDER BY date DESC;
```

<font style="color:rgb(64, 64, 64);">🔑</font><font style="color:rgb(64, 64, 64);"> 关键技术点：</font>

1. <font style="color:rgb(64, 64, 64);">CTE表达式 → 像备菜时的分步操作</font>
2. <font style="color:rgb(64, 64, 64);">窗口函数 → 智能排名计算器</font>
3. <font style="color:rgb(64, 64, 64);">95天数据 → 正好展示13周（前段按周分组）</font>

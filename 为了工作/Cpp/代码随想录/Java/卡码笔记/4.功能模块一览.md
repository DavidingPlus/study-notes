# 4.功能模块一览

# 用户端功能
## 首页
![1739552343494-668bc001-3234-4ae4-a951-7e714ce4927e.png](https://cdn.davidingplus.cn/images/2026/09/11/1739552343494-668bc001-3234-4ae4-a951-7e714ce4927e-007463.png)

采用清新简约的设计风格,打造以内容为中心的首页布局：

1. 近期笔记展示

+ 按时间顺序展示最新笔记内容
+ 每条笔记显示作者信息、发布时间
+ 支持点赞、收藏、评论等社交互动
+ 提供"展开阅读全文"功能，方便内容浏览

2. 用户贡献数据

+ 右侧面板展示"今日笔记排行榜"
+ 清晰展示用户排名和提交数
+ 显示"上月排名前三次数"和"本月排名前三次数"
+ 通过贡献热力图直观展示活跃度

3. 导航功能

+ 顶部导航栏提供"首页"、"题库"、"题单"等快速入口
+ 支持"下载笔记"功能，方便用户本地备份
+ 集成搜索功能，快速定位所需内容

4. 交互设计

+ 笔记卡片式布局，提升阅读体验
+ 每篇笔记支持点赞、收藏和评论计数
+ 作者头像和名称展示，增强社交属性
+ 发布时间显示，体现内容时效性

## 个人主页
![1739552482410-c79d24b5-c452-4fa8-8bef-a72a1997f2ce.png](https://cdn.davidingplus.cn/images/2026/09/11/1739552482410-c79d24b5-c452-4fa8-8bef-a72a1997f2ce-368567.png)

个人主页采用简洁直观的设计风格,为用户提供个性化的内容管理空间：

1. 用户信息展示

+ 顶部展示用户头像和用户名(如图中的 kama666)
+ 个性化的用户标识和基本信息展示

2. 内容分类导航

+ "笔记"和"收藏"两个主要分类标签
+ 清晰的内容分类,方便用户快速切换查看
+ 突出显示当前所在分类

3. 笔记内容展示

+ 按时间顺序展示用户的笔记列表
+ 每篇笔记显示完整标题和发布时间
+ 支持笔记内容预览
+ "展开阅读全文"功能,提供更好的阅读体验

4. 分页功能

+ 底部分页导航
+ 支持翻页浏览历史笔记内容
+ 直观的页码显示和切换

## 个人信息+个人收藏+个人笔记
![1739552939779-18df6216-8f53-4c4f-b21b-00efa5537c5c.png](https://cdn.davidingplus.cn/images/2026/09/11/1739552939779-18df6216-8f53-4c4f-b21b-00efa5537c5c-706549.png)

![1739552946184-e9bc5a3c-1772-4c46-8540-462ba5a2b5ed.png](https://cdn.davidingplus.cn/images/2026/09/11/1739552946184-e9bc5a3c-1772-4c46-8540-462ba5a2b5ed-618194.png)

![1739552952754-8397d4b6-96e1-4eb9-b796-f520f70f6f69.png](https://cdn.davidingplus.cn/images/2026/09/11/1739552952754-8397d4b6-96e1-4eb9-b796-f520f70f6f69-547586.png)

个人中心采用左侧导航 + 右侧内容的布局方式,为用户提供全面的个人信息管理和内容管理功能：

1. 个人信息管理

+ 头像展示和编辑功能
+ 基础信息设置：
+ 用户名（必填项）
+ 性别（可选择保密）
+ 生日
+ 邮箱（用于账号安全）
+ 学校
+ 个性签名
+ 所有信息支持实时编辑和保存

2. 个人收藏

+ 按分类展示收藏的内容
+ 如"计算机网络"等技术分类
+ 清晰展示收藏内容的描述
+ 支持收藏内容的快速访问和管理

3. 个人笔记

+ 展示用户创建的所有笔记
+ 按时间顺序排列展示
+ 每篇笔记显示：
+ 标题
+ 内容预览
+ "展开阅读全文"功能
+ 支持分页浏览

左侧导航栏采用简洁的图标 + 文字设计,让用户可以快速切换不同功能模块。整体设计注重用户体验,通过清晰的分类和直观的界面布局,方便用户管理个人信息和内容。

## 题库
![1739553070055-f4ac5b68-83d5-401e-9aa8-303cd78f15af.png](https://cdn.davidingplus.cn/images/2026/09/11/1739553070055-f4ac5b68-83d5-401e-9aa8-303cd78f15af-871244.png)

题库系统采用分类导航 + 表格展示的布局方式,为用户提供系统化的学习资源：

1. 左侧知识体系导航

+ 计算机基础
    - 计算机网络
    - 操作系统
    - 数据库
    - 计算机组成原理
+ Java 技术栈
    - Java 语言基础
    - Java 面向对象编程(OOP)
    - Java 集合框架
    - Java 输入输出(I/O)
    - Java Web
    - Spring/Spring Boot/Spring Cloud
    - ...
+ 清晰的层级结构,方便快速定位知识点

2. 题目列表展示

+ 核心信息一览：
    - 状态（已完成/未完成）
    - 问题 ID（唯一标识）
    - 标题（支持链接跳转）
    - 考点（明确知识点）
    - 难度（简单/中等/困难）
    - 浏览量（题目热度）
+ 分页功能支持（10条/页）
+ 可自定义每页显示数量

3. 筛选与排序

+ 难度筛选
+ 浏览量排序
+ 支持多维度组合筛选

整体设计注重学习体验：

+ 左侧知识体系清晰展示学习路径
+ 题目信息一目了然,便于选择
+ 状态标记帮助追踪学习进度
+ 难度分级适合渐进式学习
+ 浏览量反映题目热度,辅助学习方向选择

后台管理系统采用左侧导航 + 主内容区的经典布局,提供全面的系统管理功能：

1. 导航菜单

+ 仪表盘：系统概览
+ 用户管理
+ 分类管理
+ 通知管理
+ 问题管理
+ 题单管理

2. 用户管理模块

+ 用户信息展示：
    - 用户ID
    - 账号
    - 用户名
    - 管理员权限状态
    - 封禁状态
+ 搜索筛选功能：
    - 支持多条件组合查询
    - 提供"筛选"和"重置"按钮
+ 用户状态管理：
    - 显示是否为管理员
    - 显示账号状态（正常/封禁）

3. 分类管理模块

+ 分类信息展示：
    - 分类ID
    - 分类名称
    - 分类类型（父分类/子分类）
+ 操作功能：
    - 编辑
    - 删除
    - 查看
+ "创建分类"快捷按钮

4. 问题管理模块

+ 问题列表展示：
    - 问题ID
    - 标题
    - 考点
    - 难度（1-3级）
    - 浏览量
+ 筛选功能：
    - 按分类筛选
    - 支持重置
+ 分页功能（10条/页）
+ 操作选项：
    - 编辑
    - 删除

5. 题单管理模块

+ 题单信息展示：
    - 题单ID
    - 题单名称
    - 分类标签
+ 操作功能：
    - 编辑
    - 删除
    - 详情查看
+ "创建题单"快捷按钮

这样的后台管理系统设计既保证了管理效率,又确保了数据的安全性和可维护性。

# 1. 项目简介

大家好啊！欢迎大家来学习卡码笔记。

<font style="color:rgb(51, 51, 51);">卡码笔记（KamaNotes）是一个面向技术学习和知识分享的现代化笔记系统，专注于为用户提供高效、安全、便捷的笔记管理和知识分享服务。系统采用前后端分离架构，提供笔记管理、用户互动、实时通知、全文搜索等功能，支持多人协作和学习交流，致力于打造一个活跃的技术学习社区。</font>

如果你每天花费 6 小时的话，大概两周就可以学懂！本项目为入门项目，此版本为第一版本，后期我们还会补充和完善的。

# 技术选型
1. **后端技术**
    - 核心框架：Spring Boot 2.7.18
    - 安全框架：Spring Security
    - 持久层：MyBatis
    - 数据库：MySQL 8.0
    - 缓存：Redis
    - 消息推送：WebSocket
    - 搜索：MySQL 全文索引 + Jieba 分词
    - 文件存储：本地文件系统
    - 日志系统：Log4j2
    - 测试框架：JUnit
    - 模板引擎：Thymeleaf
    - Markdown：Flexmark
    - 工具库：Hutool
2. **前端技术**
    - 构建工具：Vite
    - 框架：React + TypeScript
    - 路由管理：React Router DOM
    - 状态管理：Redux Toolkit
    - UI 库：Ant Design
    - 样式：TailwindCSS
    - HTTP 客户端：Axios
    - WebSocket 客户端：原生 WebSocket
    - Markdown 渲染
    - 数据可视化
    - 代码质量：ESLint, Prettier
    - 版本控制：Husky, Lint-staged



## 做完本项目后的收获：


+ **全栈开发能力**：前后端分离架构实践（Spring Boot + React + TypeScript）。
+ **用户认证与安全**：JWT、邮箱验证码、Spring Security、权限注解控制。
+ **高性能缓存设计**：Redis 多级缓存、Sorted Set 排行榜、缓存一致性与击穿优化。
+ **搜索与性能优化**：MySQL 全文索引 + Jieba 分词，结合 Redis 提升中文搜索效率。
+ **异步与实时交互**：Redis 模拟消息队列、WebSocket 实现实时通知、消息解耦。
+ **系统健壮性**：全局异常处理、AOP + Log4j2 日志追踪、线程隔离（ThreadLocal / RequestScope）。
+ **工程实战经验**：分页设计与优化、Markdown 编辑器支持、邮件发送、数据统计。
+ **面试直击**：涵盖常考高频点——用户认证、缓存一致性、搜索优化、日志与异常处理。

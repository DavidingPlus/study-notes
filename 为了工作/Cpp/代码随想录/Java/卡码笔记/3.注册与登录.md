# 3. 注册与登录

## 注册功能
目前注册账号功能是需要通过邮箱验证。需要在 SpringBoot 集成邮箱配置功能，请参考：[邮件发送功能](https://www.yuque.com/chengxuyuancarl/px6ppg/cybvg8m5avb2egsr)

## 获取管理员权限登录
直接通过默认管理员账号可以进行登录

+ 账号：root_account
+ 密码：root12345

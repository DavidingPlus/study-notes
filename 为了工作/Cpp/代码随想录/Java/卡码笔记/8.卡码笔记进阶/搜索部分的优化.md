# 搜索部分的优化

# MySQL 搜索功能优化方案

本文档详细介绍卡码笔记系统中MySQL搜索功能的优化方案，包括全文索引、分词处理、缓存优化等。所有方案均基于实际代码实现，并在生产环境中得到验证。

## 1. 搜索功能概述

系统实现了三种核心的搜索功能：

1. **笔记全文搜索**
   * 支持标题和内容的全文检索
   * 使用 jieba 分词进行中文分词
   * 基于 MySQL FULLTEXT 索引实现
   * 结果按相关度排序
2. **用户搜索**
   * 支持用户名、账号、邮箱的组合搜索
   * 使用 CASE WHEN 实现优先级排序
   * 基于组合索引优化查询性能
3. **标签搜索**
   * 支持标签名称精确和模糊搜索
   * 支持笔记内容和标签的联合搜索
   * 使用左连接优化查询性能

ALTER TABLE note

  (CONCAT_WS(' ', title, content)) STORED;

SET @dbname = DATABASE();

  "SELECT 1",

### 2.2 查询优化

#### 2.2.1 笔记搜索优化

```sql
-- 优化后的笔记搜索（使用全文索引和相关度排序）
SELECT 
    n.*,
    MATCH(n.search_vector) AGAINST(:keyword IN NATURAL LANGUAGE MODE) as relevance
FROM note n
WHERE MATCH(n.search_vector) AGAINST(:keyword IN NATURAL LANGUAGE MODE)
ORDER BY relevance DESC
LIMIT :offset, :limit;

-- 带标签的组合搜索
SELECT DISTINCT
    n.*,
    MATCH(n.search_vector) AGAINST(:keyword IN NATURAL LANGUAGE MODE) as relevance
FROM note n
LEFT JOIN note_tag nt ON n.id = nt.note_id
LEFT JOIN tag t ON nt.tag_id = t.id
WHERE 
    MATCH(n.search_vector) AGAINST(:keyword IN NATURAL LANGUAGE MODE)
    OR t.name LIKE CONCAT('%', :tag, '%')
ORDER BY relevance DESC
LIMIT :offset, :limit;
```

#### 2.2.2 用户搜索优化

```sql
-- 优化后的用户搜索（使用前缀匹配和优先级排序）
SELECT * FROM user 
WHERE 
    username LIKE CONCAT(:keyword, '%')
    OR account LIKE CONCAT(:keyword, '%')
    OR email LIKE CONCAT(:keyword, '%')
ORDER BY 
    CASE 
        WHEN username = :keyword THEN 1
        WHEN account = :keyword THEN 2
        WHEN email = :keyword THEN 3
        WHEN username LIKE CONCAT(:keyword, '%') THEN 4
        WHEN account LIKE CONCAT(:keyword, '%') THEN 5
        WHEN email LIKE CONCAT(:keyword, '%') THEN 6
        ELSE 7
    END
LIMIT :offset, :limit;
```

### 2.3 性能优化建议

1. 索引优化：
   * 对经常搜索的字段添加合适的索引
   * 使用组合索引减少索引数量
   * 定期维护和更新索引
2. 查询优化：
   * 使用前缀匹配代替通配符匹配
   * 限制返回结果数量
   * 使用分页查询处理大结果集
3. 缓存策略：

```java
@Service
public class SearchService {
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final String SEARCH_CACHE_KEY = "search:%s:%d";
    private static final long CACHE_EXPIRE_TIME = 30; // 分钟
    
    public List<Note> searchNotes(String keyword, int page) {
        String cacheKey = String.format(SEARCH_CACHE_KEY, keyword, page);
        
        // 尝试从缓存获取
        List<Note> cachedResult = (List<Note>) redisTemplate.opsForValue()
            .get(cacheKey);
        
        if (cachedResult != null) {
            return cachedResult;
        }
        
        // 缓存未命中，执行搜索
        List<Note> result = noteMapper.searchNotes(keyword, page);
        
        // 存入缓存
        redisTemplate.opsForValue()
            .set(cacheKey, result, CACHE_EXPIRE_TIME, TimeUnit.MINUTES);
        
        return result;
    }
}
```

4. 分词处理：

```java
public class SearchUtils {
    private static final JiebaSegmenter segmenter = new JiebaSegmenter();

    public static String preprocessKeyword(String keyword) {
        // 1. 去除特殊字符
        keyword = keyword.replaceAll("[\\p{P}\\p{S}]", " ");
        
        // 2. 分词
        List<String> words = segmenter.sentenceProcess(keyword);
        
        // 3. 组合搜索词
        return String.join(" ", words);
    }
}
```

## 8. API 接口说明

### 8.1 笔记搜索

* 接口：`GET /api/search/notes`
* 参数：
  * keyword: 搜索关键词
  * page: 页码（默认1）
  * pageSize: 每页大小（默认20）
* 返回示例：

```json

            "relevance": 0.8

}
```

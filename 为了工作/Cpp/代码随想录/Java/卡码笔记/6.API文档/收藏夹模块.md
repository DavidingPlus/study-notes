# 笔记模块 API
## 批量查询收藏夹
### 请求路径
```http
GET /api/collections
```

### 简要说明
<font style="color:rgb(52, 64, 84);">如果请求参数中携带了 noteId，则需要对每个收藏夹都进行一次处理，判断其是否收藏了对应的 note。</font>

### 请求头
无

### 请求体
无

### 路径参数
无

### 查询参数
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| <font style="color:rgb(52, 64, 84);">creatorId</font> | string | 否 | 作者 Id |
| <font style="color:rgb(52, 64, 84);">noteId</font> | number | 否 | 笔记 Id |


### 请求示例
```javascript
GET /api/collections?creator=10000&note=20000 HTTP 1.1
```

### 成功响应示例
```json
{
    "code": 200,
    "msg": "",
    "data": [
        {
            "collectionId": 500001,
            "name": "收藏夹1",
            "description": "",
            "exsitCurrentNote": false
        }
    ]
}
```

## 创建收藏夹
### 请求路径
```http
POST /api/collections
```

### 简要说明
创建收藏夹功能

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | multipart/form-data | 是 | 请求体格式 |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |


### 请求体
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| name | number | 是 | 收藏夹标题 |
| description | string | 否 | 收藏夹描述 |


### 路径参数
无

### 查询参数
无

### 请求示例
```javascript
POST /api/collections HTTP 1.1
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOjEyMzQ1NiwidXNlcm5hbWUiOiJqb2huZG9lIiwicm9sZSI6ImFkbWluIiwiZXhwIjoxNjgwNzI1ODQwfQ.4kdNxfpEdH65dXszJjZpZjwhUKt27DkUPhQpJhC1Hjc
Content-Type: application/json

{
    "name": "测试收藏夹",
    "description": "测试收藏夹描述"
}
```

### 成功响应示例
```json
{
    "code": 200,
    "msg": "创建收藏夹成功",
    "data": {
        "collectionId": 4000001
    }
}
```

## 收藏笔记
### 请求路径
```http
POST /api/collections/batch
```

### 简要说明
<font style="color:rgb(52, 64, 84);">批量更新收藏夹</font>

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |
| Content-Type | application/json | 是 |  |


### 请求体
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| noteId | number | 是 | 笔记ID |
| collections | array<{collectionId, action}> | 是 |  |


### 路径参数
无

### 查询参数
无

### 请求示例
```javascript
PATCH /api/collections/batch HTTP/1.1
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOjEyMzQ1NiwidXNlcm5hbWUiOiJqb2huZG9lIiwicm9sZSI6ImFkbWluIiwiZXhwIjoxNjgwNzI1ODQwfQ.4kdNxfpEdH65dXszJjZpZjwhUKt27DkUPhQpJhC1Hjc
Content-Type: application/json

{
  "noteId": 200001,
  "collections": [
    {
      "collectionId": 500003,
      "action": "delete"
    },
    {
      "collectionId": 500004,
      "action": "create"
    }
  ]
}
```

### 成功响应示例
```json
{
    "code": 200,
    "msg": "",
    "data": null
}
```

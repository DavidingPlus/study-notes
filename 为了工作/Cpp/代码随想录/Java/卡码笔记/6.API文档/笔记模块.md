# 笔记模块 API
## 批量查询笔记
### 请求路径
```http
GET /api/notes
```

### 简要说明
该接口用于查询笔记，支持按照作者 ID、题目 ID、收藏夹 ID 查询题目。并且支持对查询结果进行分页，按照创建时间进行排序。

### 请求头
无

### 请求体
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| <font style="color:rgb(52, 64, 84);">questionId</font> | string | 否 | 问题 Id |
| <font style="color:rgb(52, 64, 84);">authorId</font> | number | 否 | 作者 Id |
| <font style="color:rgb(52, 64, 84);">collectionId</font> | string | 否 | 收藏夹 Id |
| <font style="color:rgb(52, 64, 84);">sort</font> | string | 否 | 'create' |
| <font style="color:rgb(52, 64, 84);">order</font> | string | 否 | 'asc' ｜ 'desc' |
| <font style="color:rgb(52, 64, 84);">recentDays</font> | number | 否 | 笔记日期范围 |
| <font style="color:rgb(52, 64, 84);">page</font> | number | 否 | 分页页码 |
| <font style="color:rgb(52, 64, 84);">pageSize</font> | number | 否 | 分页查询页面大小 |


### 路径参数
无

### 查询参数
无

### 请求示例
```javascript
GET /api/notes?page=1&pageSize=10 HTTP 1.1
```

## 创建笔记

```http

```

### 简要说明
用户创建笔记

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | multipart/form-data | 是 | 请求体格式 |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |


### 请求体
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| questionId | number | 是 | 题单标题 |
| content | string | 否 | 题单描述 |

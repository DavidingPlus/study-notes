# 点赞模块 API
## 点赞功能
### 请求路径
```http
POST /api/likes/note/{noteId}
```

### 简要说明
<font style="color:rgb(52, 64, 84);">对指定的资源（如笔记、评论等）进行点赞操作。</font>

### 请求头
无

### 请求体
无

### 路径参数
无

### 查询参数
无

### 请求示例
```javascript
POST /api/likes/note/100000 HTTP 1.1
```

### 成功响应示例
```json
{
    "code": 200,
    "msg": "点赞成功",
    "data": null
}
```

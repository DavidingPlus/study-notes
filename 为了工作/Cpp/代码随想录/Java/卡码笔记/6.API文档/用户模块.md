# 用户模块 API
## 用户注册
### 请求路径
```http
POST /api/users
```

### 简要说明
用户注册账号接口

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | application/json | 是 | 请求体格式（json） |


### 请求体
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| account | string | 是 | 用户账号 |
| username | string | 是 | 用户名 |
| password | string | 是 | 用户密码 |
| email | string | 是 | 用户邮箱 |
| verifyCode | string | 是 | 验证码 |


### 路径参数
无

### 查询参数
无

### 请求示例
```javascript
POST /api/users HTTP/1.1
Content-Type: application/json

{
  "account": "用户账号",
  "username" : "username",
  "email": "new@example.com",
  "password": "userpassword",
  "verifyCode": "930332"
}
```

### 成功响应示例
```json
{
    "code": 200,
    "msg": "",
    "data": {
        "userId": 10001
    },
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOjEyMzQ1NiwidXNlcm5hbWUiOiJqb2huZG9lIiwicm9sZSI6ImFkbWluIiwiZXhwIjoxNjgwNzI1ODQwfQ.4kdNxfpEdH65dXszJjZpZjwhUKt27DkUPhQpJhC1Hjc"
}
```

## 用户上传头像
### 请求路径
```http
POST /api/users/avatar
```

### 简要说明
用户上传个人头像

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | multipart/form-data | 是 | 请求体格式 |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |


### 请求体
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| file | FormData | 否 | 图片文件 |


### 路径参数
无

### 查询参数
无

### 请求示例
```javascript
POST /api/users/avatar HTTP/1.1
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOjEyMzQ1NiwidXNlcm5hbWUiOiJqb2huZG9lIiwicm9sZSI6ImFkbWluIiwiZXhwIjoxNjgwNzI1ODQwfQ.4kdNxfpEdH65dXszJjZpZjwhUKt27DkUPhQpJhC1Hjc
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary7MA4YWxkTrZu0gW

------WebKitFormBoundary7MA4YWxkTrZu0gW
Content-Disposition: form-data; name="file"; filename="avatar.png"
Content-Type: image/png

<文件内容省略>
------WebKitFormBoundary7MA4YWxkTrZu0gW
```


## 批量查询用户
### 请求路径
```http
GET /api/admin/users
```

### 简要说明
批量查询用户的接口

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | application/json | 是 | 请求体格式（json） |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |


### 请求体
无

### 路径参数
无

### 查询参数
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| <font style="color:rgb(52, 64, 84);">userId</font> | number | 否 | 用户 ID |
| <font style="color:rgb(52, 64, 84);">account</font> | string | 否 | 账号 |

| <font style="color:rgb(52, 64, 84);">isBanned</font> | number | 否 | 账号是否被封禁<br/>1: 是<br/>0: 否 |

| pageSize | number | 否 | 每页大小 |

```javascript
GET /api/admin/users?page=1&pageSize=20 HTTP/1.1
```

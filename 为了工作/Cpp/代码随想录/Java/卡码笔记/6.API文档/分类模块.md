# 分类模块 API
## 批量查询分类
### 请求路径
```http
GET /api/admin/categories
```

### 简要说明
获取分类列表

### 请求头
无

### 请求体
无

### 路径参数
无

### 查询参数
无

### 请求示例
```javascript
GET /api/admin/categories HTTP/1.1
```

### 成功响应示例
```json
{
    "code": 200,
    "msg": "",
    "data": [
        {
            "categoryId": 100000,
            "name": "计算机基础",
            "parentCategoryId": 0,
            "children": [
                {
                    "categoryId": 100001,
                    "name": "计算机网络",
                    "parentCategoryId": 100000
                },
                {
                    "categoryId": 100002,
                    "name": "操作系统",
                    "parentCategoryId": 100000
                },
                {
                    "categoryId": 100003,
                    "name": "数据库",
                    "parentCategoryId": 100000
                }
            ]
        }
    ]
}
```

## 批量查询分类
### 请求路径
```http
POST /api/admin/categories
```

### 简要说明
创建一个新的分类

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | multipart/form-data | 是 | 请求体格式 |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |


### 请求体
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| parentCategoryId | number | 是 | 父分类 ID |
| name | string | 是 | 分类名 |


### 路径参数
无

### 查询参数
无

### 请求示例
```javascript
POST /api/admin/categories HTTP/1.1
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOjEyMzQ1NiwidXNlcm5hbWUiOiJqb2huZG9lIiwicm9sZSI6ImFkbWluIiwiZXhwIjoxNjgwNzI1ODQwfQ.4kdNxfpEdH65dXszJjZpZjwhUKt27DkUPhQpJhC1Hjc
Content-Type: application/json

{
    "parentCategoryId": 0,
    "name": "Java"
}
```

### 成功响应示例
```json
{
    "code": 200,
    "msg": "",
    "data": {
        "categoryId": 100005
    }
}
```

## 更新分类信息
### 请求路径
```http
PATCH /api/admin/categories/{categoryId}
```

### 简要说明
更新指定分类的信息

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | multipart/form-data | 是 | 请求体格式 |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |


### 请求体
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| name | string | 是 | 分类名 |


### 路径参数
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| categoryId | number | 是 | 分类 ID |


### 查询参数
无

### 请求示例
```javascript
PATCH /api/admin/categories/{categoryId} HTTP/1.1
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOjEyMzQ1NiwidXNlcm5hbWUiOiJqb2huZG9lIiwicm9sZSI6ImFkbWluIiwiZXhwIjoxNjgwNzI1ODQwfQ.4kdNxfpEdH65dXszJjZpZjwhUKt27DkUPhQpJhC1Hjc

```

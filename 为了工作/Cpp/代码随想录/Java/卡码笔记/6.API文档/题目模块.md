# 题目模块 API
## 批量查询题目
### 请求路径
```http
GET /api/admin/questions
```

### 简要说明
获取题目列表

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | multipart/form-data | 是 | 请求体格式 |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |


### 请求体
无

### 路径参数
无

### 查询参数
| 名称 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| categoryId | number | 否 | 分类 ID |
| sort | string | 否 | 排序字段，枚举值<br/>view: 查看次数<br/>difficulty: 难度 |

| page | number | 否 | 分页查询页码 |
| pageSize | number | 否 | 分页查询页面大小 |

## 批量创建题目
### 请求路径
```http
POST /api/admin/questions/batch
```

### 简要说明
根据约定的格式，根据 markdown 文件批量创建题目

具体实现要求：

1. 自动创建不存在的分类，包括父分类和子分类
2. 存在的分类则将对应的题目加入到该分类下
3. 要么全部创建成功，要么全部创建失败，并返回创建失败的原因

具体格式要求：

```markdown
# 父分类

## 子分类1

* 题目1（考点：xxx）【难度】
* 题目2（考点：xxx）【难度】
* 题目3（考点：xxx）【难度】

## 子分类2

* 题目4（考点：xxx）【难度】
* 题目5（考点：xxx）【难度】
* 题目7（考点：xxx）【难度】

## 子分类3

* 题目8（考点：xxx）【难度】
* 题目9（考点：xxx）【难度】
* 题目10（考点：xxx）【难度】
```

其中，难度的取值范围为["简单", "中等", "困难"]

示例：

```markdown
# 人工智能

## 机器学习 

* 线性回归和多元线性回归有什么区别？（考点：线性回归）【简单】
* 逻辑回归和线性回归的主要区别是什么？（考点：逻辑回归）【简单】
* 什么是模型的训练误差和泛化误差？（考点：模型评估）【简单】

## 深度学习 

* 请解释什么是反向传播算法？它的工作原理是什么？（考点：神经网络基础）【简单】
* 激活函数在神经网络中起什么作用？（考点：激活函数）【简单】
* ReLU激活函数的优点和缺点是什么？（考点：激活函数）【中等】
* 如何解决梯度消失问题？（考点：梯度消失）【中等】

##  强化学习 

* 强化学习中的马尔可夫决策过程（MDP）是什么？（考点：MDP基本概念）【简单】
* 如何理解强化学习中的探索与利用平衡问题？（考点：探索与利用）【中等】
```

### 请求头
| 名称 | 示例值 | 必选 | 说明 |
| --- | --- | --- | --- |
| Content-Type | multipart/form-data | 是 | 请求体格式 |
| Authorization | Bearer eyJhbGci... | 是 | 用户 token |


### 请求体

| --- | --- | --- | --- |
| markdown | string | 是 | markdown 文本 |


### 路径参数

### 查询参数
无

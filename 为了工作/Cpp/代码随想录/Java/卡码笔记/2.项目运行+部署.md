# 2.项目运行+部署

## 开发环境搭建

### 开发环境要求

为了确保项目能够正常运行，建议使用以下或者更高版本的开发环境。

#### NodeJS

* **版本要求：**`>= 20.10`
* 用途：
  * 用于运行前端项目（Vite + React + TS）
  * 自带的包管理工具（npm）

**推荐使用** `nvm` 管理多个不同版本的 Node，方便在不同的前端项目中切换不同的 NodeJS 版本。

#### Java

* **版本要求：**`>= 17`
* 用途：
  * 后端基于 `SpringBoot` 开发，推荐使用 Java 17 LTS 版本
  * 推荐选择 `OpenJDK17`

**推荐使用** IDEA 作为编辑器，可以针对不同的项目选择不同的 Java 版本。

#### MySQL

* 版本要求：`>= 8.0`
* 用途：
  * 作为后端主数据库

#### Redis

* 版本要求：`>= 7.0`
* 用途：
  * 用作缓存，存储验证码等临时数据
  * 用作轻量的消息队列

### 开发环境搭建

#### 下载代码

克隆 [卡码笔记](https://github.com/youngyangyang04/kamanotes) 代码到本地。

```bash
git clone https://github.com/youngyangyang04/kamanotes.git
```

> 如果想要向卡码笔记提交 PR，请 fork 仓库后再 clone 自己对应的仓库。

打开克隆的项目目录，文件目录结构如下：

```bash

│   ├── pom.xml
```

#### 创建数据库

在知识星球： <https://t.zsxq.com/LlVLk> 帖子内下载 .sql 文件。

![1748499062022-7fd47103-d536-4231-ba9f-d286a24d2068.png](https://cdn.davidingplus.cn/images/2026/09/11/1748499062022-7fd47103-d536-4231-ba9f-d286a24d2068-724975.png)

登录本地的 MySQL 数据库，创建 `kamanote_tech` 数据库。

```sql
create database kamanote_tech;
```

创建完毕后执行在知识星球帖子内下载的 .sql 文件。

```sql
use kamanote_tech;
source /../kamanote.sql # 具体路径与文件名需要按照自己下载的位置以及当时的文件名确定
```

#### 修改后端配置文件

修改 SpringBoot 配置文件 `./backend/src/main/resources/application-dev.yaml` 文件，将其中的 MySQL 的配置文**件修改为自己的数据库账号和密码。**

```bash
spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/kamanote_tech?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root        # 修改为自己的数据库账号
    password: <PASSWORD>  # 修改为自己的数据库密码

upload:
  path: ${user.dir}/tmp/uploads # 指定上传文件的存储路径
  url-prefix: http://localhost:8080/images  # 访问上传文件的URL前缀
```

#### 使用命令行启动前后端

**启动前端：**

切换到 ./kamanotes/frontend 目录下，执行 install 的 run 命令。

```bash
cd ./frontend
npm install
npm run dev
```

然后在浏览器内访问 `http://localhost:5173` 地址查看前端界面。

**启动后端：**

切换到 ./kamanotes/backend 目录下，执行 maven 的命令

```bash
mvn spring-boot:run	
```

在命令输出中 `Tomcat started on port(s): 8080 (http) with context path ''`看到该字样就代表后端启动成功了。

#### 使用 IDEA 和 WebStorm 启动前后端（推荐）

在使用 IDE 的情况下，

* 使用 IDEA 以 `./kamanotes/backend` 作为项目根目录
* 使用 WebStorm 以 `./kamanotes/frontend` 作为项目根目录

分别打开项目，IDE 会智能配置启动文件。

点击右上角的运行按钮就可以运行代码了。

如果 Webstorm 没有智能配置右上角的运行按钮，可以打开 `package.json` 文件。

```json
"scripts": {
  "dev": "vite",
  "build": "tsc -b && vite build",
  "lint": "eslint .",
  "preview": "vite preview",
  "format": "prettier --write .",
  "format:check": "prettier --check .",
  "prepare": "cd .. && husky frontend/.husky",
  "lint-staged": "lint-staged"
},
```

点击 "dev": "vite" 前的运行按钮也是一样的。

卡码笔记系统项目 2024-01 ~ 至今

技术栈：Spring Boot、MyBatis、MySQL、Redis、WebSocket、Thymeleaf、React、TypeScript、Ant Design

项目描述：卡码笔记是一个前后端分离的技术笔记分享社区项目，包括前端 PC 和管理后台，用于帮助开发者记录和分享技术学习笔记，面向互联网技术人的内容分享平台。

责任描述：作为核心开发人员，主要负责用户认证、笔记管理、搜索功能、消息通知以及数据统计模块的开发工作。

核心技术：

• 通过邮箱验证码和 JWT Token 实现用户认证，采用 Spring Security 框架进行安全控制，实现了基于注解的接口权限管理，提升系统安全性。

• 基于 Redis 实现验证码存储和频率限制，采用 Thymeleaf 模板引擎实现邮件发送，确保验证码的时效性和安全性。

• 基于 Spring 提供的 RequestScope 注解在拦截器中统一处理用户认证信息，减少数据库查询次数。

• 采用 HandlerExceptionResolver 实现全局异常处理，统一异常响应格式，优化了系统的可维护性。

• 使用 Markdown 编辑器实现笔记编写功能，支持图片上传、预览、代码高亮等特性。

• 采用 React + TypeScript 开发前端界面，使用 Ant Design 组件库构建用户界面，实现响应式设计。

• 基于 AOP + Log4j2 实现系统日志记录，对接口调用、异常信息进行全面监控和追踪。

• 使用 MyBatis 实现数据访问层，采用动态 SQL 和批量操作优化数据库性能，提升系统吞吐量。

# 后端写法

项目名称：卡码笔记系统 2024-01 ~ 至今

技术栈：Spring Boot、MyBatis、MySQL、Redis、WebSocket、JWT、Thymeleaf、Log4j2

项目描述：卡码笔记是一个前后端分离的技术笔记分享平台后端系统，提供用户认证、笔记管理、搜索服务、消息通知等核心功能的 API 接口，用于帮助开发者记录和分享技术学习笔记。

责任描述：作为核心研发人员，主要负责用户认证、笔记管理、搜索功能、消息通知以及数据统计模块的开发工作。

核心技术：

* **用户认证与自动登录**：实现了基于邮箱验证码与 JWT Token 的用户认证机制。识别用户信息并生成 Token，实现无缝的自动登录体验。
* **全局异常处理**：采用 `HandlerExceptionResolver` 实现全局异常处理，提升了系统的健壮性和可维护性，优化了用户体验。
* **用户信息处理**：基于 Spring 提供的 RequestScope 注解在拦截器中统一保存处理用户信息，减少数据库查询次数。
* **日志追踪与监控**：利用 AOP 和 Log4j2 实现接口访问日志记录，便于任务追踪、实时监控和快速诊断。
* **邮件模板引擎**：通过 Thymeleaf 实现邮件发送功能，支持自定义验证码邮件模板渲染，提升邮件内容的个性化与灵活性。

#### <font style="color:rgb(6, 6, 7);">工作描述</font>

+ **<font style="color:rgb(6, 6, 7);">版本一</font>**<font style="color:rgb(6, 6, 7);">：实现基础RPC功能，包括服务注册与远程调用。</font>
+ **<font style="color:rgb(6, 6, 7);">版本二</font>**<font style="color:rgb(6, 6, 7);">：添加Netty自定义编码器、解码器和序列化器，创建缓存机制。</font>
+ **<font style="color:rgb(6, 6, 7);">版本三</font>**<font style="color:rgb(6, 6, 7);">：引入负载均衡、超时重试及白名单机制。</font>

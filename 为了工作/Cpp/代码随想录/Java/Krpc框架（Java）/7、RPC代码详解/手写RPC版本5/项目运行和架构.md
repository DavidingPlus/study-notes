# <font style="color:rgb(51, 51, 51);">环境检查</font>
## <font style="color:rgb(51, 51, 51);">1. 检查Java版本</font>
```bash
java -version
```

<font style="color:rgb(51, 51, 51);">确保输出显示的是JDK 17或更高版本。如果不是，需要：</font>

**<font style="color:rgb(51, 51, 51);">Windows环境：</font>**

+ **<font style="color:rgb(51, 51, 51);">设置JAVA_HOME环境变量指向JDK 17安装目录（例如：D:\software\JDK17）</font>**
+ **<font style="color:rgb(51, 51, 51);">将JDK 17的bin目录添加到PATH环境变量</font>**

**<font style="color:rgb(51, 51, 51);">Mac环境：</font>**

```bash
# 使用brew安装JDK 17
brew install openjdk@17

# 设置JAVA_HOME（添加到 ~/.zshrc 或 ~/.bash_profile）
export JAVA_HOME=$(/usr/libexec/java_home -v 17)
export PATH=$JAVA_HOME/bin:$PATH

# 使环境变量生效
source ~/.zshrc  # 或 source ~/.bash_profile
```

**<font style="color:rgb(51, 51, 51);">Linux环境：</font>**

```bash
# Ubuntu/Debian系统安装JDK 17
sudo apt update
sudo apt install openjdk-17-jdk

# CentOS/RHEL系统安装JDK 17
sudo yum install java-17-openjdk-devel

# 设置JAVA_HOME（添加到 ~/.bashrc）
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk
export PATH=$JAVA_HOME/bin:$PATH

# 使环境变量生效
source ~/.bashrc
```

# 常见问题处理
## 1. 找不到主类
检查jar包中的类路径是否正确，确保所有依赖都在classpath中。

## 2. 依赖缺失
如果遇到依赖缺失的错误，执行：

```bash
mvn dependency:tree
```

检查依赖关系，并确保所有依赖都已下载到本地仓库。

## 3. ZooKeeper连接失败
+ 确保ZooKeeper服务已启动
+ 检查防火墙设置
+ 验证连接地址和端口是否正确

Mac/Linux环境检查ZooKeeper状态：

```bash
# 检查进程
ps aux | grep zookeeper

# 检查端口
netstat -an | grep 2181

# 检查日志
# Mac
tail -f /usr/local/var/log/zookeeper/zookeeper.log
# Linux
tail -f /var/log/zookeeper/zookeeper.log
```

## 4. Java版本不匹配
如果遇到版本不匹配的错误，确保使用JDK 17：

```bash
# Windows
D:\software\JDK17\bin\java -version

# Mac/Linux
java -version
```

## 5. 权限问题（Mac/Linux特有）
如果遇到权限问题：

```bash
# 修改项目目录权限
chmod -R 755 /path/to/version5

# 修改执行权限
chmod +x /path/to/version5/krpc-provider/target/*.jar
chmod +x /path/to/version5/krpc-consumer/target/*.jar
```

## 6.ZK 报错
1.首先删除现有的配置

```bash
# 停止服务
sudo systemctl stop zookeeper

# 删除旧的服务文件
sudo rm /etc/systemd/system/zookeeper.service

# 删除旧的 ZooKeeper 包（如果有）
sudo apt remove zookeeper zookeeperd
sudo apt autoremove
```

2.重新安装 ZK

```bash
# 更新包列表
sudo apt update

# 安装 ZooKeeper
sudo apt install zookeeper zookeeperd
```

3.创建新的配置文件：

```bash
# 创建服务文件
sudo nano /etc/systemd/system/zookeeper.service
```

添加以下内容

```bash
[Unit]
Description=Apache ZooKeeper server
Documentation=http://zookeeper.apache.org
Requires=network.target remote-fs.target
After=network.target remote-fs.target

[Service]
Type=forking
Environment=JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
ExecStart=/usr/share/zookeeper/bin/zkServer.sh start
ExecStop=/usr/share/zookeeper/bin/zkServer.sh stop
ExecReload=/usr/share/zookeeper/bin/zkServer.sh restart
WorkingDirectory=/var/lib/zookeeper

[Install]
WantedBy=multi-user.target
```

4.重新加载并启动服务

```bash
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启动 ZooKeeper
sudo systemctl start zookeeper

# 检查状态
sudo systemctl status zookeeper

# 设置开机自启
sudo systemctl enable zookeeper
```

5.验证 ZK 是否正常运行

```bash
# 检查端口
sudo netstat -anlp | grep 2181

# 检查进程
ps aux | grep zookeeper

# 使用客户端测试
/usr/share/zookeeper/bin/zkCli.sh -server 127.0.0.1:2181
```

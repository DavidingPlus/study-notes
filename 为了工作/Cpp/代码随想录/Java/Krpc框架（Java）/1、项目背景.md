# <font style="color:rgb(59, 67, 81);">项目目的</font>
随着业务的快速发展和系统规模的不断扩大，**单体架构逐渐暴露出许多问题**，如**性能瓶颈、扩展性**差等。为了应对这些问题，**微服务架构应运而生**，通过将单一系统拆分为多个**独立的服务模块**，提高了系统的**灵活性和可扩展性**。不同服务模块之间的通信需要借助**<font style="color:#000000;">RPC（远程过程调用）框架</font>**，它能实现不同服务器之间的**高效通信**。

通过仿照市场主流RPC框架的设计思想，我们将使用**<font style="color:#000000;">Java</font>**<font style="color:#000000;">语言手动实现一个高性能、高可用性的RPC框架。本项目不仅帮助 </font>**<font style="color:#000000;">录友</font>**<font style="color:#000000;"> 深入理解</font>**<font style="color:#000000;">RPC框架</font>**<font style="color:#000000;">的设计与实现，也能提升解决</font>**分布式系统中常见问题**的能力。

# 为什么要学习 RPC 框架？
无论你是**经验丰富的开发者**，还是**刚入门的新人**，**RPC框架**都是**分布式系统中的核心技术之一**。RPC的**最大作用**在于，它能够让我们像调用本地方法一样发起**远程调用**，并屏**蔽网络通信的复杂性**。RPC框架作为微服务架构的基础，不仅广泛应用于服务之间的远程调用、负载均衡和服务发现，也广泛运用在分布式系统中，例如**gRPC**用于**etcd服务的通信。**

通过学习**RPC框架**，你将能掌握**如何设计与实现高效、可靠的服务通信方案**，提升系统的**可扩展性和可维护性**。

# 如何学习 RPC？
学习RPC并不难，关键是从基础到深入，逐步掌握其核心技术。首先，你需要了解RPC的基础概念，如**序列化、网络编程和通信协议**等。然后，学习如何在RPC框架中实现**健康检测、负载均衡、异常重试、熔断限流**等技术，最终通过项目实践将这些理论转化为实际应用。  

# RPC 的作用是什么？
+ 屏蔽远程调用与本地调用的差异，让开发者以一致的方式调用远程服务。
+ 隐藏底层网络通信的复杂性，使开发者能够专注于业务逻辑的实现。
+ 提供高效、可靠的服务通信解决方案，是分布式系统的基础。

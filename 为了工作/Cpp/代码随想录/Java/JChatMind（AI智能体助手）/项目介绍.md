# 项目介绍

## 一、项目简介

![1766397132861-a9e37267-f089-4b54-b9f6-f8c11cb1ebe2.png](./img/CpkOIMH5HBAo7Cd9/1766397132861-a9e37267-f089-4b54-b9f6-f8c11cb1ebe2-961713.png)

JChatMind 是一个**智能 AI Agent 系统**，基于 Spring AI 框架构建，实现了自主决策、工具调用和知识库检索等核心能力。系统采用 **Think-Execute 循环机制**，能够理解复杂任务、规划执行步骤、调用外部工具，并基于 RAG 技术从知识库中检索相关信息，完成多步骤的复杂任务。

## 三、核心功能

### 智能 Agent 引擎

* **Think-Execute 循环**：实现自主决策和执行机制，支持多轮工具调用
* **状态管理**：完善的状态机管理 Agent 生命周期（IDLE、THINKING、EXECUTING、FINISHED、ERROR）
* **任务规划**：能够将复杂任务分解为多个步骤，自主规划执行顺序

### 工具调用系统

* **可扩展架构**：支持固定工具和可选工具的灵活配置
* **内置工具**：知识库检索、直接回答、任务终止等固定工具
* **扩展工具**：数据库查询、文件操作、邮件发送等可选工具
* **工具注册**：自动发现和注册工具，支持动态添加新工具

### RAG 知识库检索

* **文档管理**：支持 Markdown 文档上传、解析和存储
* **向量检索**：基于 pgvector 实现语义相似度搜索
* **智能分块**：按章节自动分块，保持语义完整性
* **多知识库**：支持多个知识库，Agent 可灵活选择

### 多模型支持

* **统一接口**：通过 Spring AI 统一接口支持多种大语言模型
* **动态切换**：注册表模式实现模型动态切换，无需修改代码
* **已支持模型**：DeepSeek、智谱AI（GLM-4.6）
* **易于扩展**：添加新模型只需配置和创建 Bean

### 实时通信

* **SSE 推送**：服务端主动推送 Agent 执行状态
* **消息持久化**：完整的对话历史记录，支持上下文恢复

## 四、项目架构图

![1766571568147-b534cd88-f91c-4cf5-a157-496fce1f95aa.png](./img/CpkOIMH5HBAo7Cd9/1766571568147-b534cd88-f91c-4cf5-a157-496fce1f95aa-344942.png)

JChatMind 采用**典型的分层架构设计**，从上到下分为：**展现层、应用层、API 层、服务层、基础层**，职责清晰、扩展性强。

### 展现层（Web 端）

负责用户交互与结果展示，包括：

* 知识库管理界面
* 聊天会话展示
* Agent 执行状态实时可视化\
  通过 SSE 接收后端推送，实时展示 Agent 的思考与执行过程。

### 应用层

承载具体业务能力，主要包含三类模块：

* **知识库模块**：创建知识库、上传与管理文档
* **聊天会话模块**：会话加载、会话管理、上下文维护
* **智能体模块**：模型选择、参数配置、知识库选择、工具配置\
  这一层更贴近“产品能力”，不关心底层实现细节。

### API 层

对外提供统一的 RESTful API：

* 前端只和 API 层交互
* 屏蔽内部服务复杂度
* 便于后续拆分微服务或接入其他客户端

### 服务层（系统核心）

这是整个系统的**核心逻辑层**：

* **智能体管理**：Agent 定义、配置、生命周期控制（Think-Execute 循环）
* **聊天会话管理**：会话生命周期与上下文维护
* **RAG 服务**：文档写入、向量化、相似度检索
* **工具调用服务**：文件、数据库、邮件等工具的统一调度
* **SSE 服务**：连接维护与消息实时推送
* **Markdown 解析**：文档分块、标题提取，服务于 RAG

### 基础层

提供稳定的基础能力支撑：

* **PostgreSQL + pgvector**：同时存储业务数据与向量数据
* **Ollama 本地模型服务**：支持本地 LLM 与向量模型推理，降低成本、增强可控性

### 数据库记录分析

这是一个在大多数平台未来可能都需要的一个功能——模型能够访问数据库中的内容，并对内容进行分析。

本部分的场景我们设计了一个电商系统，让模型访问电商系统中的评论表中的内容，对用户的评论进行分析，并将分析结果发送到系统负责人的邮箱，以改进产品体验和优化未来的工作方向。

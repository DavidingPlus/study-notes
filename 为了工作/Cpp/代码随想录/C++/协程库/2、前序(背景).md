# 2、前序(背景)

## <font style="color:#333333;">为什么要做协程库？</font>
### 这个问题有可能在面试中会被询问。
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">如果你已经写了星球里的分布式存储项目，其中本身就包含一个协程模块，并且直接引用了该项目。那么在学习 Raft 之后你就会发现，这个协程库相当于自己造的一个轮子，能够提升项目的新颖度与灵活性。</font>

<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">具体来说，协程的核心价值在于：当程序在执行 read、socket 等系统调用发生阻塞时，协程可以先切换去执行其他任务，等阻塞条件满足后再回来继续执行，从而大幅提升系统的灵活性。具体实现细节学完之后就会更清楚。</font>

## 做协程主要原因有几点：
### 1、拓展知识的深度和广度
 	面试时，面试官通常会先问进程、线程，然后很大概率继续追问协程是什么。学习过程中，你肯定已经对进程、线程有了充分理解，比如进程是系统资源（CPU、内存）分配的基本单位，线程是 CPU 调度的基本单位。那协程又是什么？协程是一种高效的并发编程技术，尤其适合大量 I/O 密集型或并发任务场景，能够提升程序性能与可维护性，让异步代码可以像同步代码一样编写，显著降低异步编程的复杂度。  

### 2、协程是个轮子，可以配合项目增加系统的灵活性
<font style="color:rgb(0, 0, 0);background-color:rgba(0, 0, 0, 0);">可以把协程库集成到自己的项目中。比如在执行 read、write 等系统调用时，如果资源暂时不可用并返回 EAGAIN，此时 CPU 不能空等，完全可以让 CPU 去处理其他任务，而协程就是实现这种机制的优秀方案。</font>

**<font style="color:#DF2A3F;background-color:rgba(0, 0, 0, 0);">协程库可以引入到 WebServer、Raft 共识算法等项目中，大幅简化异步操作，让代码更易理解、更易维护。这样一来，即使是市面上比较常见、“烂大街” 的项目，也能做出新意和亮点。</font>**

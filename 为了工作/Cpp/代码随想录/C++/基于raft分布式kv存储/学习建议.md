### 常见问题以及为什么会有这个一键配置环境的脚本:

<font style="color:rgb(47, 48, 52);">Raft项目环境问题 看了很多朋友在配置Raft的时候都出现了不一样的问题，但是这里可能只能解决大多数人会遇到的问题。 </font>

**<font style="color:rgb(47, 48, 52);">首先：</font>**<font style="color:rgb(47, 48, 52);"> </font>

<font style="color:rgb(47, 48, 52);">1.protobuf版本：这个问题可能很多在使用作者make的时候第一行就会出现响应的错误。 解决：这个问题有两种办法，第一就说使用ubuntu 22.0.4的版本，</font>**<font style="color:rgb(47, 48, 52);">sudo apt-get install protobuf-compiler libprotobuf-dev</font>**<font style="color:rgb(47, 48, 52);">.直接使用这个命令既可以下载到3.12.4\[作者同款]。</font>

<font style="color:rgb(47, 48, 52);">第二种办法</font><https://github.com/protocolbuffers/protobuf/releases/tag/v3.12.4> <font style="color:rgb(47, 48, 52);">在这里下载protobuf-cpp-3.12.4-zip 解压后依次运行./configure make sudo make install.\[不推荐！] </font>

<font style="color:rgb(47, 48, 52);"></font>

<font style="color:rgb(47, 48, 52);">2.muduo的问题：很多朋友可能github使用不是熟练，或者git不下来代码等问题，还有运行muduo中./build.sh会出现运行代码的错误，比如某个代码出现了什么问题。 解决办法：这里已经将出现问题或者可能出现问题的代码进行修改，具体原因是因为boost的版本将一些旧的东西删除了。 </font>

<font style="color:rgb(47, 48, 52);"></font>

<font style="color:rgb(47, 48, 52);">3.大多数人走到前面两步已经心累了对配环境，发现项目的make也出现问题什么找不到portobuf等，这个问题第一步讲了解决办法我就不再提了。 相信大多数人可能都是卡在这几步了，部分可能卡在cmake 的版本或者gcc上，或者运行后非法指令(这个问题我还没遇到)，希望这个文章能帮到你，或者重新按我给的方法配环境。  </font>

## <font style="color:#117CEE;">Raft项目中bin文件下的可执行程序测试了什么功能？</font>

通过运行，以下命令：

```shell
cd KVstorageBaseRaft-cpp // 进入项目目录
mkdir cmake-build-debug
cd cmake-build-debug
cmake ..
make
```

会在Raft项目中bin文件下生成一系列测试功能的可执行程序，如图：

![1737524116192-6b4515ec-7b32-4154-9db2-e26f8a0a971a.png](https://cdn.davidingplus.cn/images/2026/09/11/1737524116192-6b4515ec-7b32-4154-9db2-e26f8a0a971a-665148.png)

其中有，以下测试功能：

### <font style="color:#117CEE;">Rpc测试功能：</font>

* <font style="color:rgb(31, 35, 40);">provider</font>
* <font style="color:rgb(31, 35, 40);">consumer</font>

这两个可执行文件代表rpc的服务端provider，和Rpc客户端consumer，目的是为了测试RPC通信是否正常。

```shell
通过以下命令运行，先运行服务端，再运行客户端。
cd bin
./provider
```

![rpc1.jpg](https://cdn.davidingplus.cn/images/2026/09/11/rpc1-948895.jpeg)<font style="color:#117CEE;">\ </font>再开一个新窗口，运行Rpc客户端

```shell
./consumer
```

![rpc2.jpg](https://cdn.davidingplus.cn/images/2026/09/11/rpc2-548874.jpeg)

**<font style="color:rgb(31, 35, 40);">注意先运行provider，再运行consumer，原因很简单：需要先提供rpc服务，才能去调用。</font>**

### <font style="color:#117CEE;">测试Raft集群：</font>

在bin中运行可执行程序raftCoreRun，出现下面图的内容代表Raft集群运行成功。

```shell
// make sure you in bin directory ,and this has a test.conf file
cd bin
//这里是新的补充，别忘记先启动provider后再运行这个
//开一个新的窗口
.provider
//第二个窗口
./raftCoreRun -n 3 -f test.conf
```

![raft.jpg](https://cdn.davidingplus.cn/images/2026/09/11/raft-635527.jpeg)

## 前置知识储备

在学习该项目之前，必须知道的内容有：

**c++：**

c++语法基础学完面向对象的三大原则：继承、封装、多态等，最好掌握模板，虚函数，以及相关的容器或者算法。

c11部分新特性：auto、RAII、mutex等。

### 分布式基础:

* CAP定理：理解一致性、可用性和分区容错性之间的权衡。
* 一致性协议：了解Raft协议的基本原理，以及它如何保证分布式系统中一致性和领导选举。
* 数据复制：理解数据在多个节点之间如何复制，以确保可用性和容错性。
* 故障处理与恢复：了解分布式系统如何处理节点失败及恢复过程。
* 分布式理论：<https://cloud.tencent.com/developer/article/1860632>
* 分布式简单入门知识集合：<https://erdengk.top/archives/fen-bu-shi-jian-dan-ru-men-zhi-shi>

### Raft协议：

* Raft协议概念：理解Raft的核心概念，包括领导选举、日志复制、日志一致性等。
* 状态机：Raft协议通过复制状态机的状态来保证一致性，需要了解状态机如何在分布式系统中运行。
* 日志复制机制：理解Raft是如何通过日志条目复制来确保数据的一致性，并在节点失败时如何恢复。
* 资料参考：<https://blog.csdn.net/m0_73756442/article/details/142955670>

### KV数据库基础：

* \*\*\*\*键值存储：理解键值数据库的基本工作原理，包括如何存储和检索数据。
* 数据模型：理解如何设计KV数据库的数据结构，如何通过Raft协议实现数据的分布式存储。

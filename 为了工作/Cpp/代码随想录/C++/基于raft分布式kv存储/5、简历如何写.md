# 5、简历如何写

**<font style="color:rgb(47, 48, 52);">基于Raf共识算法的分布式KV存储数据库</font>**

**<font style="color:rgb(47, 48, 52);">项目描述 </font>**

<font style="color:rgb(47, 48, 52);">本项目是基于Raft共识算法的分布式K-V数据库，具备线性一致性和分区容错性，在少于半数节点发生故障仍可正常对外提供服务。使用个人实现的RPC通信框架MprRpc和跳表数据库SKipListPro完成RPC功能和K-V存储功能。</font>

<font style="color:rgb(47, 48, 52);"></font>

**<font style="color:rgb(47, 48, 52);">主要工作:</font>**

1. <font style="color:rgb(47, 48, 52);">基于protobuf和自定义协议实现RPC通信框架MprRpc通信框架完成各节点之间的远程调用和数据传递功能:</font>
2. <font style="color:rgb(47, 48, 52);">基于跳表数据结构实现跳表数据库SkipListPro完成K-V存储功能;</font>
3. <font style="color:rgb(47, 48, 52);">实现Raft协议的心跳与选举机制，通过定时线程池触发心跳与选举任务，并维护集群的日志提交状态，</font>
4. <font style="color:rgb(47, 48, 52);">实现日志读写与提交，由领导节点处理客户端的读写请求，并将日志复制至跟随者节点，在超过半数节点复制成功后提交日志，应用命令至状态机并返回响应给客户端:</font>
5. <font style="color:rgb(47, 48, 52);">实现客户端协议，包括在客户端协议中加入由ip和请求序号组成的“请求id”以保证线性一致性，以及客户端重试等功能。</font>



**项目难点**

<font style="color:rgb(47, 48, 52);">难点就是项目主要的几个功能模块的实现。</font>

1. <font style="color:rgb(47, 48, 52);">Raft算法的理解与实现</font>
2. <font style="color:rgb(47, 48, 52);">RPC通信框架的理解与实现</font>
3. <font style="color:rgb(47, 48, 52);">k-v数据库</font>



**<font style="color:rgb(47, 48, 52);">个人收获：</font>**

+ 系统掌握 **Raft 共识协议原理、状态转换机制与日志一致性流程**，深入理解分布式一致性模型。
+ 独立完成从零到一的 **分布式存储系统设计与实现**，涵盖网络通信、协议编解码、存储引擎、客户端接口等全流程。
+ 提升了 **系统架构设计、模块解耦与并发编程** 能力，强化了对分布式系统中**高可用、高一致性、高性能设计的理解与实践能力**。
+ 深刻体会到了工程化开发中从原理落地到工程实现过程中的挑战与解决思路，具备进一步参与复杂后端系统开发的能力。

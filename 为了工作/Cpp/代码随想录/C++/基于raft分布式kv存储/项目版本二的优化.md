# 项目版本二的优化

**2024年12月份发布第二版本**

**相比于版本一优化了什么？**

做了逻辑的分层结构，让复习以及学习需要的知识点更加清晰。



**开篇背景：**

增加了使用分布式除了可以解决性能扩展的问题，也可以依靠分布式备份数据防止数据丢失。



**技能需求与分析**

+ ****学习这个项目需要掌握的技能部分，做了更详细的说明。
+ 比如c++基础要求、raft的学习博客、KV的学习博客、RPC的博客提供学习。
+ 并且补充了学习raft或rpc的连接、视频等，以及RPC在本项目中运用的测试文件提供学习。



**Raft理论**

相比于原文档进行了理论上的分层梳理。



**代码模块讲解**

1、补充了部分注释，简化了原文档冗余的注释。

2、增加了部分关键函数的流程解释。

3、做了更清晰的目录。

4、补充了RPC部分在原文档中的仓库位置，实现了方便阅读方便查看。

5、对原文的内容进行整合基本原文档的部分内容有关代码部分全在该模块，并且通过目录就可以学习你想要的。



**常见问题：**

对其部分未回答的地方，做出回答和增加了perf火焰图的学习博客，当然最好自己找适合自己的资料。
